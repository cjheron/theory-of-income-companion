Stable Subspaces and Linear Systems

Covers Local Stability slides 16–29 · About 35 min · Prerequisites: Lesson 33 (stability and almost-reciprocal pairs), linear algebra: eigenvalues, eigenvectors, diagonalization
By the end you can:
  1. write the linearized system \(y_{t+1}=Ay_t\) in terms of the Jacobian \(A\) of the vector-valued optimal policy;
  2. diagonalize \(A=P^{-1}\Lambda P\) and solve the transformed system \(z_{i,t+1}=\lambda_i z_{i,t}\) in closed form;
  3. define the stable subspace \(E^s\) as the span of eigenvectors with \(|\lambda_i|\lt1\) and state the convergence condition;
  4. count the degrees of freedom for initial conditions and state the three canonical cases: all stable, all unstable, and the saddle-point case;
  5. describe the Jordan decomposition and explain why stability still requires \(|\lambda_k|\lt1\) for each Jordan block.
Primary source Alvarez, Local Stability of Optimal Trajectories, Linearization, slides 16–29. The underlying linear algebra is covered in any first graduate linear algebra text; a readable reference with an economics focus is Strang, Linear Algebra and Its Applications (5th ed.), Ch. 5–6. For the connection to dynamics, Luenberger, Introduction to Dynamic Systems (1979), Ch. 5, gives an excellent treatment of stable subspaces and the Jordan form in discrete time.
Notation for this lesson
  • \(n\) — number of state variables in the multi-dimensional problem.
  • \(\xi_t\equiv x_t-x^*\in\mathbb R^n\) — deviation from steady state at date \(t\).
  • \(A\in\mathbb R^{n\times n}\) — Jacobian of the optimal policy at the steady state: \(A=Dg(x^*)\).
  • \(\lambda_1,\ldots,\lambda_n\) — eigenvalues of \(A\) (counted with multiplicity).
  • \(E^s\) — stable subspace (span of eigenvectors/generalized eigenvectors with \(|\lambda_i|\lt1\)).
  • \(m\) — dimension of \(E^s\) = number of eigenvalues (counted with multiplicity) inside the unit circle.

1. The multi-dimensional linearized system

In Lesson 33 we linearized the scalar policy \(g(x)\) to get \(\xi_{t+1}\approx g'(x^*)\xi_t\). With \(n\) state variables, the optimal policy is a vector-valued function \(g:\mathbb R^n\to\mathbb R^n\), and the linearization is a matrix equation. Stab p.16

Taylor-expanding \(g\) around \(x^*\):

$$x_{t+1}-x^*=g(x_t)-g(x^*)\approx Dg(x^*)(x_t-x^*)$$

where \(Dg(x^*)\) is the \(n\times n\) Jacobian matrix. Writing \(y_t\equiv x_t-x^*\):

$$y_{t+1}=Ay_t,\qquad A\equiv Dg(x^*)\in\mathbb R^{n\times n}.$$

The sequence \(\{y_t\}_{t\ge0}\) is a linear, time-invariant (LTI) dynamical system. The question "does \(x_t\to x^*\)?" becomes "does \(y_t\to0\)?".

What \(A\) encodes

Entry \(A_{ij}\) is the first-order effect of a small increase in state \(j\) today on optimal state \(i\) tomorrow. When \(n=1\), \(A=[g'(x^*)]\) and we recover the scalar case. When \(n=2\) (say capital \(k\) and bonds \(b\)), \(A\) captures cross-effects: how being above steady-state capital changes the speed of bond adjustment.

2. Diagonalizing the system

Suppose \(A\) has \(n\) linearly independent eigenvectors \(v_1,\ldots,v_n\) with eigenvalues \(\lambda_1,\ldots,\lambda_n\). Write the full eigenvector decomposition as \(AP=P\Lambda\) where: Stab p.17

  • \(P=[v_1|\cdots|v_n]\) — the \(n\times n\) matrix of column eigenvectors,
  • \(\Lambda=\text{diag}(\lambda_1,\ldots,\lambda_n)\) — diagonal matrix of eigenvalues.

Equivalently, \(A=P\Lambda P^{-1}\) (since \(P\) is invertible). Define the transformed variable:

$$z_t\equiv P^{-1}y_t.$$

Then \(y_{t+1}=Ay_t\) becomes \(Pz_{t+1}=P\Lambda P^{-1}Pz_t=P\Lambda z_t\), so:

$$z_{t+1}=\Lambda z_t.$$

This is \(n\) independent scalar equations:

$$z_{i,t+1}=\lambda_i\, z_{i,t},\quad i=1,\ldots,n.$$

Each scalar equation solves explicitly: \(z_{i,t}=\lambda_i^t\, z_{i,0}\). Therefore:

$$y_t=Pz_t=\sum_{i=1}^n z_{i,0}\,\lambda_i^t\, v_i.$$
Convergence condition Stab p.18

\(y_t\to0\) as \(t\to\infty\) if and only if \(z_{i,0}=0\) for every \(i\) with \(|\lambda_i|\ge1\).

  • For \(|\lambda_i|\lt1\): \(\lambda_i^t\to0\), so component \(z_{i,0}v_i\lambda_i^t\to0\) regardless of \(z_{i,0}\).
  • For \(|\lambda_i|\ge1\): \(|\lambda_i|^t\ge1\) for all \(t\); if \(z_{i,0}\ne0\) this component does not vanish.

The condition \(z_{i,0}=0\) for all \(i\) with \(|\lambda_i|\ge1\) is a constraint on the initial deviation \(y_0=x_0-x^*\). Let \(m\) be the number of eigenvalues strictly inside the unit circle. Then there are \(n-m\) eigenvalues with \(|\lambda_i|\ge1\), and convergence requires \(n-m\) independent linear constraints on \(y_0\).

3. The stable subspace \(E^s\)

Stable subspace \(E^s\) Stab p.20

The stable subspace of \(A\) is the linear span of eigenvectors corresponding to eigenvalues with modulus strictly less than one:

$$E^s\equiv\text{span}\{v_i:|\lambda_i|\lt1\}.$$

\(\dim(E^s)=m\) (the number of stable eigenvalues, counted with multiplicity). An initial condition \(y_0\) leads to \(y_t\to0\) if and only if \(y_0\in E^s\).

Geometric picture in \(\mathbb R^2\)

Suppose \(n=2\) with \(\lambda_1\in(-1,1)\) and \(\lambda_2>1\). The stable subspace \(E^s\) is the line through the origin spanned by \(v_1\). Points on this line converge to the origin; all other points diverge. The "saddle" shape familiar from neoclassical growth phase diagrams is exactly the \(n=2\) case of this structure — except there the phase plane depicts \((k_t,c_t)\), and the stable manifold is the optimal path.

4. Three canonical cases

The dimension \(m\) of \(E^s\) determines the nature of the dynamics. Stab p.20

Three cases
Case \(m=n\): globally stable steady state
All \(n\) eigenvalues satisfy \(|\lambda_i|\lt1\). Every initial condition \(y_0\in\mathbb R^n\) converges to 0. The optimal path starting from any \(x_0\) near \(x^*\) converges to \(x^*\). No constraints on \(x_0\).
Case \(m=0\): globally unstable steady state
All \(n\) eigenvalues satisfy \(|\lambda_i|\ge1\). Only the trivial initial condition \(y_0=0\) (i.e., \(x_0=x^*\)) converges. Any other starting point diverges. All \(n\) components of \(x_0\) are constrained to equal \(x_i^*\).
Case \(0\lt m\lt n\): saddle-point
There are \(m\) stable eigenvalues and \(n-m\) unstable. Convergence requires \(y_0\in E^s\), which imposes \(n-m\) independent constraints on the \(n\) components of \(y_0=x_0-x^*\). If \(x_0\) is a free initial condition (not chosen by the planner), there are generically \(n-m\) components of \(x_0\) that must jump to satisfy these constraints. If \(m=n/2\), the problem is called a saddle-point problem: exactly half the eigenvalues are stable.
Saddle-point property in macro

In the neoclassical growth model with \(n=2\) (capital \(k\) and consumption \(c\)), the state vector is \((k,c)\). Capital \(k\) is predetermined (set by previous investment decisions); \(c\) is a "jump variable" chosen at each instant. The saddle-point property says \(m=1\): one eigenvalue inside the unit circle. The convergence condition imposes one constraint on \((k_0, c_0)\): given \(k_0\), there is exactly one \(c_0\) that puts \((k_0,c_0)\) on the stable manifold. This one-dimensional stable manifold is the saddle path of the phase diagram.

5. Counting constraints and free initial conditions

To make the counting precise, we need to distinguish between predetermined and jump variables. Stab p.21

In a problem with \(n\) state variables, suppose \(k\) of them are predetermined at \(t=0\) (their initial values are fixed by history or endowments) and \(n-k\) are jump variables (control variables that can be freely chosen at \(t=0\)). The convergence condition \(y_0\in E^s\) imposes \(n-m\) linear constraints. For a unique stable path:

$$(\text{number of constraints}) = (\text{number of free initial conditions}) \quad\Leftrightarrow\quad n-m=n-k \quad\Leftrightarrow\quad m=k.$$

So the problem is determinate (has a unique stable path) when the number of stable eigenvalues equals the number of predetermined variables. When \(m>k\) there are multiple stable paths (indeterminacy); when \(m\lt k\) there is no stable path generically.

Blanchard–Kahn condition (discrete time)

A system \(y_{t+1}=Ay_t\) with \(k\) predetermined variables and \(n-k\) jump variables has a unique locally stable solution if and only if \(A\) has exactly \(k\) eigenvalues strictly inside the unit circle (i.e., \(m=k\)). This is the discrete-time version of the Blanchard–Kahn (1980) determinacy condition.

6. Jordan decomposition (advanced)

The analysis in §2 assumed \(A\) has \(n\) linearly independent eigenvectors. This fails when eigenvalues have algebraic multiplicity greater than geometric multiplicity — i.e., when \(A\) is not diagonalizable. The Jordan decomposition handles the general case. Stab p.25

Jordan form

Every real matrix \(A\) is similar to a block-diagonal matrix \(J\): there exists invertible \(P\) such that \(A=PJP^{-1}\), where \(J=\text{diag}(J_1,\ldots,J_r)\) and each Jordan block is:

$$J_k=\begin{pmatrix}\lambda_k&1&&\\&\lambda_k&\ddots&\\&&\ddots&1\\&&&\lambda_k\end{pmatrix}\in\mathbb R^{s_k\times s_k}.$$

A Jordan block of size \(s_k>1\) arises when the eigenspace for \(\lambda_k\) is defective (dimension less than algebraic multiplicity \(s_k\)).

For a \(2\times2\) Jordan block with eigenvalue \(\lambda_k\):

$$J_k^t=\begin{pmatrix}\lambda_k&1\\0&\lambda_k\end{pmatrix}^t=\lambda_k^{t-1}\begin{pmatrix}\lambda_k&t\\0&\lambda_k\end{pmatrix}=\begin{pmatrix}\lambda_k^t&t\lambda_k^{t-1}\\0&\lambda_k^t\end{pmatrix}.$$

The key insight: \(t\lambda_k^{t-1}\to0\) as \(t\to\infty\) if and only if \(|\lambda_k|\lt1\). The \(t\) factor (polynomial growth) is dominated by the exponential decay \(|\lambda_k|^t\). Therefore: Stab p.27

Stability under Jordan form

The system \(y_{t+1}=Ay_t\) is stable (all trajectories \(y_t\to0\)) if and only if all eigenvalues of \(A\) satisfy \(|\lambda_k|\lt1\). The size of Jordan blocks does not affect the stability criterion — only the eigenvalue moduli matter. For convergence at rate \(O(\rho^t)\) with \(\rho\lt1\), we need all eigenvalues to satisfy \(|\lambda_k|\le\rho\).

Why Jordan blocks don't change the criterion

A Jordan block causes polynomial amplification: a deviation \(y_0\) in the generalized eigenspace of \(\lambda_k\) produces a trajectory \(\sim t^{s_k-1}\lambda_k^t\) in norm. But \(t^p\lambda_k^t\to0\) for any polynomial power \(p\) whenever \(|\lambda_k|\lt1\). The exponential beats the polynomial. This is the same reason that \(e^{-t}\cdot t^p\to0\) for any fixed \(p\) in continuous time.

7. Quiz

1. The stable subspace \(E^s\) is:
  • the full space \(\mathbb R^n\) whenever the steady state is a minimum
  • the set of initial conditions where the Euler equation is satisfied
  • the span of eigenvectors of \(A=Dg(x^*)\) with \(|\lambda_i|\lt1\)
  • the orthogonal complement of the unstable eigenspace of \(A\)
\(E^s\) is the span of eigenvectors (and generalized eigenvectors, in the Jordan-block case) corresponding to eigenvalues strictly inside the unit circle. Option (d) is wrong: the stable and unstable subspaces are not generally orthogonal (unless \(A\) is symmetric). Option (b) describes the entire trajectory, not just the initial condition.
2. For the 2D system \(y_{t+1}=Ay_t\) with \(\lambda_1=0.4\) and \(\lambda_2=1.5\), the Blanchard–Kahn condition for a unique stable path requires:
  • both initial conditions \(y_{1,0}\) and \(y_{2,0}\) to be predetermined
  • exactly one variable to be predetermined and one to be a jump variable
  • both variables to be jump variables, with no constraints on initial conditions
  • the eigenvalues to satisfy \(\lambda_1\lambda_2=1\) which fails here
There is \(m=1\) stable eigenvalue (\(\lambda_1=0.4\)). The Blanchard–Kahn condition requires \(m=k\) where \(k\) is the number of predetermined variables. So exactly \(k=1\) predetermined variable and \(n-k=1\) jump variable. The jump variable absorbs the one convergence constraint.
3. Under diagonalization \(A=P\Lambda P^{-1}\), the transformed variable \(z_t=P^{-1}y_t\) evolves as:
  • \(z_{t+1}=P^{-1}z_t\) — mixed by the inverse eigenvector matrix
  • \(z_{t+1}=\Lambda^{-1}z_t\) — governed by the inverse eigenvalues
  • \(z_{t+1}=Pz_t\) — mixed by the eigenvector matrix
  • \(z_{t+1}=\Lambda z_t\) — \(n\) independent scalar equations \(z_{i,t+1}=\lambda_i z_{i,t}\)
Substituting: \(z_{t+1}=P^{-1}y_{t+1}=P^{-1}Ay_t=P^{-1}(P\Lambda P^{-1})y_t=\Lambda P^{-1}y_t=\Lambda z_t\). So \(z_{t+1}=\Lambda z_t\), which is \(n\) independent scalar equations — this is the whole point of the transformation.
4. A \(3\times3\) Jordan block with eigenvalue \(\lambda=-0.5\) produces trajectories of the form:
  • oscillating with amplitude shrinking at rate \(t^2(-0.5)^t\to0\)
  • diverging at rate \(t^2(-0.5)^{-t}\to\infty\)
  • converging to a cycle of period 2 at amplitude 1
  • constant at the initial value since \(|\lambda|\lt1\)
\(J^t_{3\times3}\) produces terms up to \(t^2\lambda^{t-2}\). For \(\lambda=-0.5\): sign alternates (oscillating) and \(t^2\cdot0.5^t\to0\). Option (c) is wrong — a cycle requires eigenvalues on the unit circle. Option (d) is wrong — Jordan blocks produce polynomial growth in \(t\), not constants, though both decay.

8. True or false?

  1. If \(A\) has two eigenvalues inside the unit circle and one outside, then the initial condition \(y_0\) must satisfy 2 independent constraints for the trajectory to converge.
    Answer
    False. With \(n=3\) states, \(m=2\) stable eigenvalues, and \(n-m=1\) unstable eigenvalue, convergence requires \(n-m=1\) constraint on \(y_0\) (not 2). The constraint zeros out the component along the unstable eigenvector; the two stable components can be non-zero and still converge.
  2. If a matrix is not diagonalizable (i.e., has a Jordan block), then its stable subspace is not well defined.
    Answer
    False. The stable subspace is well defined in the Jordan-form case too: it is the span of generalized eigenvectors corresponding to eigenvalues with \(|\lambda_k|\lt1\). The only change from the diagonalizable case is that "eigenvectors" must be replaced by "generalized eigenvectors" (chains associated with Jordan blocks).
  3. The Blanchard–Kahn condition \(m=k\) guarantees global stability (convergence from any starting point).
    Answer
    False. The Blanchard–Kahn condition guarantees local uniqueness of a stable path — given any set of predetermined initial conditions, there is a unique choice of jump variables that places the system on \(E^s\). But \(E^s\) is a local object (defined by the Jacobian at the steady state), so this is only a local result. Global stability requires separate analysis.
  4. The solution \(y_t=\sum_{i=1}^n z_{i,0}\lambda_i^t v_i\) shows that only the unstable eigendirections determine long-run behavior.
    Answer
    False, sort of. In the long run, stable directions (\(|\lambda_i|\lt1\)) vanish so the unstable directions dominate if \(z_{i,0}\ne0\) for any unstable \(\lambda_i\). But on the optimal path, we set \(z_{i,0}=0\) for all unstable \(i\): the optimal path lies in \(E^s\), so long-run behavior is governed entirely by the stable eigendirections. The statement mixes unconditional and conditional behavior.

9. Exercises

Exercise 34.1 Stab p.19 (finding the stable subspace)

Let \(A=\begin{pmatrix}0.3&0.4\\0&1.2\end{pmatrix}\).

  1. Find the eigenvalues and eigenvectors of \(A\). (5 pts)
  2. Write down the stable subspace \(E^s\) explicitly as a subspace of \(\mathbb R^2\). (5 pts)
  3. Find the initial condition \((y_{1,0},y_{2,0})\) on \(E^s\) with \(y_{1,0}=1\). What must \(y_{2,0}\) be? (5 pts)
  4. Verify by computing \(y_1=Ay_0\), \(y_2=Ay_1\), \(y_3=Ay_2\) explicitly. Do the components decay at rate \(\lambda_1=0.3\)? (5 pts)
Hint

\(A\) is upper triangular so the eigenvalues are the diagonal entries. For the stable eigenvector (eigenvalue 0.3), solve \((A-0.3I)v=0\). For the stable subspace: any scalar multiple of this eigenvector.

Show solution

(a) Since \(A\) is upper triangular, \(\lambda_1=0.3\) and \(\lambda_2=1.2\). Eigenvector for \(\lambda_1=0.3\): \((A-0.3I)v=0\Rightarrow\begin{pmatrix}0&0.4\\0&0.9\end{pmatrix}v=0\Rightarrow v_1=\begin{pmatrix}1\\0\end{pmatrix}\). Eigenvector for \(\lambda_2=1.2\): \((A-1.2I)v=0\Rightarrow\begin{pmatrix}-0.9&0.4\\0&0\end{pmatrix}v=0\Rightarrow v_2=\begin{pmatrix}4\\9\end{pmatrix}\) (or any multiple).

(b) \(E^s=\text{span}\{v_1\}=\{(c,0):c\in\mathbb R\}\) — the \(y_1\)-axis.

(c) For \(y_0\in E^s\) with \(y_{1,0}=1\): \(y_0=(1,0)\), so \(y_{2,0}=0\).

(d) \(y_1=A(1,0)^T=(0.3,0)^T\); \(y_2=A(0.3,0)^T=(0.09,0)^T\); \(y_3=A(0.09,0)^T=(0.027,0)^T\). Yes: \(y_{1,t}=0.3^t\to0\) and \(y_{2,t}=0\) throughout.

Exercise 34.2 Exam-style (Blanchard–Kahn counting)

An economy has three state variables: capital stock \(k\), government debt \(b\), and consumption \(c\). The linearized system around the steady state has Jacobian \(A\) with eigenvalues \(\lambda_1=0.5\), \(\lambda_2=0.7\), \(\lambda_3=1.4\).

  1. How many predetermined variables must there be for the Blanchard–Kahn condition to hold? Which of \((k,b,c)\) are likely predetermined? (5 pts)
  2. Describe what the stable manifold looks like geometrically in this 3D system. (5 pts)
  3. Now suppose the government changes policy and the new Jacobian has eigenvalues \(0.5, 0.7, 0.8\). Is the system still determinate? What happens to any jump variable? (5 pts)
  4. And if the new eigenvalues are \(0.5, 1.2, 1.4\)? Is the system still determinate? (5 pts)
Hint

Blanchard–Kahn: number of stable eigenvalues (\(|\lambda_i|\lt1\)) must equal number of predetermined variables. Capital \(k\) and debt \(b\) are stock variables (predetermined by history); consumption \(c\) is a flow (jump variable).

Show solution

(a) \(m=2\) eigenvalues inside the unit circle (0.5 and 0.7). Blanchard–Kahn requires \(k=m=2\) predetermined variables. Capital \(k\) and government debt \(b\) are stocks set by past decisions — they are predetermined. Consumption \(c\) is the jump variable chosen at each date.

(b) The stable manifold \(E^s\) is a 2-dimensional subspace (plane through the origin in \(\mathbb R^3\)) spanned by the two stable eigenvectors of \(A\). For given \((k_0-k^*, b_0-b^*)\), there is a unique \(c_0-c^*\) on this plane — that is the equilibrium jump.

(c) All three eigenvalues are now inside the unit circle: \(m=3\). With still \(k=2\) predetermined variables, \(m=3>k=2\): indeterminacy. There are infinitely many stable paths — the economy can jump to multiple different \(c_0\) values and still converge. Policy is too passive to pin down a unique path.

(d) Now \(m=1\) (only eigenvalue 0.5 is inside the unit circle). With \(k=2\) predetermined variables but only \(m=1\) stable eigenvalue: \(m=1\lt k=2\). The convergence condition imposes \(n-m=2\) constraints, but there is only \(n-k=1\) free jump variable — one too few. Generically, no stable path exists. The policy creates an explosive equilibrium.

Exercise 34.3 Stab p.26 (Jordan block computation)

Let \(A=\begin{pmatrix}0.6&1\\0&0.6\end{pmatrix}\) — a \(2\times2\) Jordan block with \(\lambda=0.6\).

  1. Compute \(A^t\) exactly. (5 pts)
  2. Starting from \(y_0=(1,1)^T\), compute the trajectory \(y_t=A^ty_0\) and verify that \(y_t\to0\). At what rate does the second component \(y_{2,t}\) converge? (5 pts)
  3. Contrast with what would happen if \(A=\begin{pmatrix}1.4&1\\0&1.4\end{pmatrix}\). (5 pts)
Hint

For a Jordan block \(J=\lambda I+N\) where \(N\) is the nilpotent shift, \(J^t=\sum_{k=0}^{s-1}\binom{t}{k}\lambda^{t-k}N^k\). For a \(2\times2\) block: \(J^t=\begin{pmatrix}\lambda^t & t\lambda^{t-1}\\0&\lambda^t\end{pmatrix}\).

Show solution

(a) \(A^t=\begin{pmatrix}0.6^t&t\cdot0.6^{t-1}\\0&0.6^t\end{pmatrix}\).

(b) \(y_t=A^t(1,1)^T=\begin{pmatrix}0.6^t+t\cdot0.6^{t-1}\\0.6^t\end{pmatrix}\). Component 2: \(y_{2,t}=0.6^t\to0\). Component 1: \(y_{1,t}=0.6^{t-1}(0.6+t)=0.6^{t-1}(0.6+t)\). Since \(t\to\infty\) but \(0.6^{t-1}\) shrinks faster (exponential beats polynomial), \(y_{1,t}\to0\). Rate: for large \(t\), \(y_{1,t}\approx t\cdot0.6^{t-1}\), which decays at rate slightly slower than \(0.6^t\) but still \(\to0\).

(c) With \(\lambda=1.4\): \(A^t=\begin{pmatrix}1.4^t&t\cdot1.4^{t-1}\\0&1.4^t\end{pmatrix}\). Now \(1.4^t\to\infty\), so \(y_t\to\infty\) for any \(y_0\ne0\). The polynomial factor \(t\) is dominated by the exponential growth \(1.4^t\). The steady state is unstable.

Exercise 34.4 Exam-style (complex eigenvalues)

Suppose the Jacobian \(A\) has complex eigenvalues \(\lambda_{1,2}=\rho e^{\pm i\theta}\) where \(\rho>0\) and \(\theta\ne0,\pi\).

  1. Show that \(|\lambda_{1,2}|=\rho\). What is the stability condition? (3 pts)
  2. What is the qualitative behavior of a trajectory starting near the steady state when \(\rho\lt1\)? (5 pts)
  3. In the neoclassical growth model, can the eigenvalue \(\lambda_1=g'(k^*)\) be complex? Relate to the sign of the discriminant of \(\tilde Q(\lambda)\) in Lesson 33. (7 pts)
Hint

Recall \(|e^{i\theta}|=1\), so \(|\rho e^{i\theta}|=\rho\). For the trajectory: use \(A^t v\sim\rho^t[\cos(t\theta)w_1+\sin(t\theta)w_2]\) for real vectors \(w_1,w_2\). For (c): the discriminant of \(\tilde Q\) is \([1+1/\beta+\rho_f/\rho_U]^2-4/\beta\). What is its sign?

Show solution

(a) \(|\rho e^{i\theta}|=\rho|e^{i\theta}|=\rho\). Stability requires \(\rho\lt1\).

(b) With \(\rho\lt1\): the trajectory spirals inward toward the steady state, oscillating with period \(2\pi/\theta\) while decaying geometrically at rate \(\rho^t\). Each deviation changes sign roughly every \(\pi/\theta\) periods. This is called "damped oscillatory convergence."

(c) The discriminant of \(\tilde Q(\lambda)=\lambda^2-[1+1/\beta+\rho_f/\rho_U]\lambda+1/\beta\) is \(\Delta=[1+1/\beta+\rho_f/\rho_U]^2-4/\beta\). For typical parameter values (\(\beta\approx0.95\), \(\rho_f/\rho_U>0\)), the coefficient in brackets is at least \(1+1/0.95\approx2.05\), so \(\Delta\gt(2.05)^2-4/0.95=4.20-4.21\approx-0.01\). This can be negative! When \(\Delta\lt0\), the roots are complex conjugates \(\lambda_{1,2}=\mu\pm i\nu\) with modulus \(\sqrt{\mu^2+\nu^2}=\sqrt{1/\beta}\approx\sqrt{1.053}=1.026>1\) — both roots outside the unit circle, so this would be Case II in Lesson 33. However, we showed \(\tilde Q(1)\lt0\), which is inconsistent with complex roots: a real upward parabola with \(\tilde Q(0)>0\) and \(\tilde Q(1)\lt0\) must have two real roots with one in \((0,1)\). So in the standard neoclassical model with log utility and Cobb-Douglas technology, \(\Delta>0\) and \(g'(k^*)\) is real.

Key takeaways

  • The linearized system \(y_{t+1}=Ay_t\) with \(A=Dg(x^*)\) reduces to \(n\) independent scalar equations \(z_{i,t+1}=\lambda_iz_{i,t}\) after diagonalization \(z_t=P^{-1}y_t\).
  • Convergence \(y_t\to0\) requires \(z_{i,0}=0\) for each eigenvalue \(|\lambda_i|\ge1\). This imposes \(n-m\) constraints on \(y_0\), where \(m=\dim(E^s)\) is the number of stable eigenvalues.
  • Three cases: (i) \(m=n\) — all eigenvalues stable, every initial condition converges; (ii) \(m=0\) — all unstable, only \(x_0=x^*\) converges; (iii) \(0\lt m\lt n\) — saddle-point, convergence requires \(y_0\in E^s\).
  • Blanchard–Kahn: for a unique stable path, the number of stable eigenvalues must equal the number of predetermined state variables (\(m=k\)).
  • Jordan form: non-diagonalizable matrices produce polynomial-times-exponential trajectories (\(t^p\lambda^t\)), but stability still requires \(|\lambda|\lt1\). The polynomial factor cannot overcome exponential decay.

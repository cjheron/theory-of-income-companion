Stochastic Bellman Equation and Markov Processes

1. Markov processes

We want to introduce uncertainty into the dynamic programming framework. The key modelling choice is to represent the exogenous shock as a first-order Markov process: the probability distribution of tomorrow's shock depends only on today's shock, not on the full history Stoch p.3.

Definition: First-order Markov process

An exogenous stochastic process \(\{z_t\}_{t\ge0}\), \(z_t\in Z\), is first-order Markov if for all \(t\ge0\) and all measurable sets \(A\subseteq Z\),

$$\Pr\{z_{t+1}\in A\mid z_t,z_{t-1},\ldots,z_0\}=\Pr\{z_{t+1}\in A\mid z_t\}\equiv Q(A\mid z_t).$$

The function \(Q:Z\times\mathcal B(Z)\to[0,1]\) is called the transition probability (or stochastic kernel). For each fixed \(z\), \(Q(\cdot\mid z)\) is a probability measure on \(Z\).

Finite state space. When \(Z=\{\zeta_1,\ldots,\zeta_n\}\), we can represent \(Q\) as an \(n\times n\) transition matrix \(P\) with entries

$$P_{ij}=Q(z'=\zeta_j\mid z=\zeta_i)\ge0,\qquad\sum_{j=1}^n P_{ij}=1\text{ for each }i.$$

Row \(i\) of \(P\) is the probability distribution over next-period states when the current state is \(\zeta_i\).

Continuous state space. When \(Z=[\underline z,\bar z]\subseteq\mathbb R^n\), a leading example is the AR(1) with heteroskedasticity:

$$z_{t+1}=\mu(z_t)+\sigma(z_t)\,e_{t+1},\quad\{e_t\}\text{ i.i.d.},\;E[e_t]=0,\;E[e_t^2]=1,$$

where \(\mu:Z\to\mathbb R\) and \(\sigma:Z\to\mathbb R_{++}\). If \(e_{t+1}\) has CDF \(H\), then the conditional CDF of \(z_{t+1}\) given \(z_t=z\) is

$$F(a\mid z)=\Pr\{z_{t+1}\le a\mid z_t=z\}=H\!\left(\frac{a-\mu(z)}{\sigma(z)}\right).$$
Why the Markov property is enough

The Markov property is a sufficient statistic condition: once you know the current shock \(z_t\), the entire past history \((z_{t-1},z_{t-2},\ldots)\) adds no information about the future. This is enormously convenient: the agent never needs to remember the full history to make optimal decisions. It is why dynamic programming — a recursive method that only tracks the current state — can characterize the full solution. Any AR(p) or higher-order process can be converted to a first-order Markov process by expanding the state to include enough lags.

2. Computing expectations under a Markov process

Once we have the transition kernel \(Q\), we can compute multi-step expectations Stoch p.4.

History. Define the history up to date \(t\) as \(z^t\equiv(z_0,z_1,\ldots,z_t)\). The joint probability of a history conditional on \(z_0\) factorizes as:

$$Q^{(t)}(z^t\mid z_0)=\prod_{s=0}^{t-1}Q(z_{s+1}\mid z_s).$$

Finite state chain. For a function \(\phi:Z\to\mathbb R\), represent it as a column vector \(\phi=(\phi_1,\ldots,\phi_n)'\) where \(\phi_j=\phi(\zeta_j)\). Then Stoch p.5:

$$E[\phi(z_t)\mid z_0=\zeta_i]=\sum_{j=1}^n\phi_j\,[P^t]_{ij}.$$

That is, the \(t\)-step expectation operator is \(P^t\), the \(t\)-th power of the transition matrix. For a function of the history, expectations are computed by summing over \((z_1,\ldots,z_t)\in Z^t\) using \(Q^{(t)}\).

Continuous state. For the AR(1) example with \(Z\subseteq\mathbb R\) Stoch p.6:

$$E[\phi(z_{t+1})\mid z_t=z]=\int_{z'\in Z}\phi(z')\,Q(dz'\mid z).$$

When \(Q(dz'\mid z)=F'(z'\mid z)\,dz'\), this is an ordinary integral. For the AR(1) with \(e\sim H\):

$$E[\phi(z_{t+1})\mid z_t=z]=\int\phi(\mu(z)+\sigma(z)e)\,dH(e).$$

3. The decision problem with uncertainty

The agent now faces a stochastic environment. At each date \(t\), the state is the pair \((x_t,z_t)\), where \(x_t\in X\) is the endogenous state (chosen by the agent) and \(z_t\in Z\) is the exogenous shock Stoch p.7.

Timing:

  1. The agent observes \((x_t,z_t)\).
  2. The agent chooses \(x_{t+1}\in\Gamma(x_t,z_t)\), where the feasibility correspondence now depends on the shock.
  3. Nature draws \(z_{t+1}\) from \(Q(\cdot\mid z_t)\).
  4. Period return \(F(x_t,x_{t+1},z_t)\) is realized.

The agent's objective is expected discounted utility Stoch p.8:

$$V^*(x_0,z_0)=\max_{\{x_{t+1}(z^t)\}}\sum_{t=0}^\infty\beta^t E\bigl[F(x_t(z^{t-1}),x_{t+1}(z^t),z_t)\bigm|z_0\bigr],$$

subject to \(x_{t+1}(z^t)\in\Gamma(x_t(z^{t-1}),z_t)\) for all \(t\ge0\) and all histories \(z^t\in Z^{t+1}\), with \((x_0,z_0)\) given.

Note that \(x_{t+1}(z^t)\) depends on the full history \(z^t=(z_0,\ldots,z_t)\), since all past shocks may be relevant to current decisions in principle. A key result (from regularity conditions the course takes as given) is that the optimal policy can be written as a Markov policy: \(x_{t+1}=g(x_t,z_t)\), depending only on the current state Stoch p.7.

Notation: history dependence vs. Markov policy

In the stochastic case, \(x_t\) depends on the history \(z^{t-1}=(z_0,\ldots,z_{t-1})\): we sometimes write \(x_t(z^{t-1})\) to emphasize this. The optimal Markov policy \(g(x,z)\) suppresses this history dependence — it uses only the current state \((x,z)\). The fact that such a policy is optimal (and not just a simplification) is a consequence of the Markov structure of \(z\) and regularity conditions on \(\Gamma\) and \(F\); we do not prove it here.

4. The stochastic Bellman operator

By the same logic as the deterministic case, we look for a function \(V:X\times Z\to\mathbb R\) satisfying a recursive equation — the stochastic Bellman equation Stoch p.10.

Definition: Stochastic Bellman operator

Define the operator \(T\) on bounded functions \(V:X\times Z\to\mathbb R\) by

$$(TV)(x,z)=\max_{x'\in\Gamma(x,z)}\left\{F(x,x',z)+\beta\int_{z'\in Z}V(x',z')\,Q(dz'\mid z)\right\}.$$

Equivalently, writing the expectation operator as \(E[\cdot\mid z]\):

$$(TV)(x,z)=\max_{x'\in\Gamma(x,z)}\bigl\{F(x,x',z)+\beta E[V(x',z')\mid z]\bigr\}.$$

The stochastic Bellman equation is the fixed-point condition \(V=TV\), i.e.

$$V(x,z)=\max_{x'\in\Gamma(x,z)}\left\{F(x,x',z)+\beta\int V(x',z')\,Q(dz'\mid z)\right\}\quad\text{for all }(x,z)\in X\times Z.$$
Theorem: Principle of Optimality (stochastic)

Under the standard boundedness and existence conditions (maintained throughout), the principle of optimality holds: \(V=TV\) if and only if \(V=V^*\), where \(V^*\) is the optimal value function of the sequence problem. In particular:

  1. The Bellman operator \(T\) has a unique fixed point \(V^*\) in the space of bounded continuous functions on \(X\times Z\).
  2. Iterations \(T^n V_0\) converge to \(V^*\) for any starting function \(V_0\).

The proof is entirely analogous to the deterministic case: \(T\) satisfies the Blackwell sufficient conditions (monotonicity and discounting) and is therefore a contraction on the sup-norm metric space.

Why the same logic works

The key step in the deterministic principle of optimality was approximating the infinite-horizon value arbitrarily well by finite-horizon truncations, using the discount factor to bound the tail. Exactly the same argument works here: the expectation operator is linear and bounded, so \(\beta^T E[V(x_T,z_T)]\to0\) as \(T\to\infty\) under boundedness. The stochastic structure affects the continuation value \(\beta\int V(x',z')Q(dz'|z)\) but not the logic of the approximation.

5. The Feller property

To establish continuity and monotonicity of \(V^*(x,z)\) in the shock \(z\), we need a property of the transition kernel \(Q\) that ensures the expectation operator preserves these properties Stoch p.12.

Definition: Feller property

For a function \(\phi:Z\to\mathbb R\), define the conditional expectation operator:

$$(E\phi)(z)\equiv\int_{z'\in Z}\phi(z')\,Q(dz'\mid z).$$

The transition probability \(Q\) has the Feller property if: whenever \(\phi\) is continuous and bounded, \(E\phi\) is also continuous and bounded.

Theorem: Properties of Q

Let \(Q\) be a transition probability on \(Z\).

  1. Feller (continuity): If \(Q\) has the Feller property, then whenever \(\phi:Z\to\mathbb R\) is continuous, the function \(z\mapsto E[\phi(z')\mid z]\) is also continuous in \(z\). This can be used to establish that \(V^*(x,z)\) is continuous in \(z\).
  2. Monotonicity: If \(\phi:Z\to\mathbb R\) is monotone (say increasing), and \(Q(\cdot\mid z)\) is first-order stochastically increasing in \(z\) — meaning higher \(z\) puts more probability on higher \(z'\) — then \(E[\phi(z')\mid z]\) is also increasing in \(z\). This can be used to establish that \(V^*(x,z)\) is increasing in \(z\).

The AR(1) example \(z_{t+1}=\mu(z_t)+\sigma(z_t)e_{t+1}\) has the Feller property whenever \(\mu\) is continuous; it satisfies first-order stochastic dominance in \(z\) whenever \(\mu\) is increasing.

Economic interpretation of Feller

The Feller property says that the expectation operator is a "smoothing" operation in the shock space: a continuous promise about the future maps to a continuous present valuation. Without this, small changes in the current shock \(z\) could cause the continuation value to jump discontinuously, which would prevent us from using calculus to derive optimality conditions. In practice, most standard Markov processes used in macro (AR(1) for TFP, Markov chain approximations, etc.) satisfy Feller.

6. Envelope condition and first-order conditions

Assume \(F(\cdot,\cdot,z)\) is differentiable, the feasibility correspondence \(\Gamma\) is smooth, and the optimal policy \(g(x,z)\in\text{Int}\,\Gamma(x,z)\) (interior solution). Then we can differentiate the Bellman equation Stoch p.13.

First-order condition. Differentiating the right-hand side of the Bellman equation with respect to \(x'\) and evaluating at \(x'=g(x,z)\):

$$0=F_y(x,g(x,z),z)+\beta\int_{z'\in Z}V_x(g(x,z),z')\,Q(dz'\mid z),$$

where the subscript \(y\) on \(F\) denotes the derivative with respect to the second argument (next period's state), and \(V_x\) is the derivative of the value function with respect to the first argument.

Envelope condition. Differentiating the Bellman equation with respect to \(x\) (the current state) and applying the envelope theorem — the derivative of the max equals the partial derivative of the objective, since at the optimum \(g(x,z)\) the derivative with respect to \(x\) through \(x'\) is zero by the FOC:

$$V_x(x,z)=F_x(x,g(x,z),z),$$

where the subscript \(x\) on \(F\) denotes the derivative with respect to the first argument (current state). This is the stochastic analogue of the Benveniste–Scheinkman theorem: the derivative of the value function equals the partial derivative of the return with respect to the current state, holding the control fixed at its optimal value.

Why the envelope holds in the stochastic case

The logic is identical to the deterministic case: changing \(x\) by \(\epsilon\) has two effects on the right-hand side of the Bellman equation — a direct effect through \(F_x\) and an indirect effect through the optimal choice \(g(x,z)\) changing. By the first-order condition, the indirect effect is zero at the optimum (the envelope principle). The expectation \(\beta\int V_x(g,z')Q(dz'|z)\) does not involve \(x\) directly, so it disappears from the derivative with respect to \(x\). What remains is exactly \(F_x(x,g(x,z),z)\).

7. The stochastic Euler equation

Combining the FOC and the envelope condition eliminates \(V_x\) and gives the central optimality condition for stochastic problems Stoch p.13.

From the envelope: \(V_x(g(x,z),z')=F_x(g(x,z),g(g(x,z),z'),z')\). Substituting into the FOC:

$$0=F_y(x,g(x,z),z)+\beta\int F_x(g(x,z),g(g(x,z),z'),z')\,Q(dz'\mid z).$$

Rewriting in time-index notation with \(x_t\equiv x\), \(x_{t+1}\equiv g(x_t,z_t)\), \(x_{t+2}\equiv g(x_{t+1},z_{t+1})\):

Theorem: Stochastic Euler equation
$$0=F_y(x_t,x_{t+1},z_t)+\beta E_t\bigl[F_x(x_{t+1},x_{t+2},z_{t+1})\bigr],$$

for all histories \(z^t=(z_0,\ldots,z_t)\) and all \(t\ge1\), where \(E_t[\cdot]\equiv E[\cdot\mid z^t]\). Equivalently:

$$0=F_y(x_t,x_{t+1},z_t)+\beta E_t\bigl[F_x(x_{t+1},x_{t+2},z_{t+1})\bigr],\quad\text{for all }z^t\text{ and }t\ge1.$$
Economic interpretation

The stochastic Euler equation says that you cannot gain by shifting one unit of the state variable across adjacent periods, even after integrating over uncertainty. The left term \(F_y\) is the marginal cost of transferring a unit of \(x\) from period \(t\) to \(t+1\) (the foregone period-\(t\) return from having less state). The right term \(\beta E_t[F_x]\) is the expected present-value marginal benefit in period \(t+1\). At the optimum these balance exactly — not in every realization of \(z_{t+1}\), but in expectation conditional on the current information \(z^t\). This is a stochastic Ramsey condition: "smooth consumption optimally given current information".

Example: neoclassical growth. With \(F(k,k',z)=U(zf(k)-k')\), the envelope gives \(V_k=U'(c)zf'(k)\) and the FOC gives \(U'(c_t)=\beta E_t[V_k(k_{t+1},z_{t+1})]\), so the stochastic Euler is:

$$U'(c_t)=\beta E_t\bigl[U'(c_{t+1})\,z_{t+1}f'(k_{t+1})\bigr].$$

This is the familiar stochastic consumption Euler equation: the marginal utility today equals the expected discounted marginal utility tomorrow times the gross return.

8. Transversality condition

Just as in the deterministic case, the Euler equation alone is necessary but not sufficient for optimality. We also need a transversality condition (TC) that rules out "oversaving" paths that satisfy the Euler equation but accumulate unlimited wealth Stoch p.14.

Theorem: Stochastic transversality condition

Under regularity conditions (maintained), the stochastic TC is:

$$0=\lim_{T\to\infty}\beta^T\int_{(z_1,\ldots,z_T)\in Z^T}F_x\bigl(x_T(z^{T-1}),x_{T+1}(z^T),z_T\bigr)\cdot x_T(z^{T-1})\cdot Q^{(T)}(dz^T\mid z_0),$$

where the integral is over all histories and \(Q^{(T)}(dz^T|z_0)=\prod_{s=0}^{T-1}Q(dz_{s+1}|z_s)\). In words: the expected present-discounted value of the shadow price of the state times the state itself goes to zero as the horizon grows.

Economic meaning of the stochastic TC

The TC rules out "Ponzi schemes" and "oversaving" paths. If \(\beta^T E_0[F_x(x_T,x_{T+1},z_T)\cdot x_T]>0\) in the limit, the agent is permanently holding assets whose marginal value is positive — they could increase welfare by planning to consume some of that wealth at some point in the future. The TC says that in the optimal plan, all the wealth is eventually "spoken for" in terms of its contribution to the agent's welfare. The stochastic version integrates this condition over all possible future histories, since the state \(x_T\) depends on the realized history \(z^{T-1}\).

Technical note on the stochastic TC

The stochastic transversality condition requires additional regularity conditions beyond the deterministic case: integrability of the integrand (so that the integral is well-defined), admissibility of the strategy (so that expected utility is finite), and additional measurability conditions. The economic argument for why the TC must hold is the same as in the deterministic case, but a fully rigorous proof requires these conditions, which are beyond the scope of this course. See SLP Chapter 9 for a complete treatment.

9. Quiz

Which statement correctly describes the first-order Markov property?

  • The transition probability depends on the current and previous period's shock
  • The distribution of tomorrow's shock depends only on today's shock, not the full history
  • The shock is independent and identically distributed across periods
  • The transition matrix has eigenvalues all equal to one
The first-order Markov property says \(\Pr\{z_{t+1}\in A\mid z_t,z_{t-1},\ldots\}=\Pr\{z_{t+1}\in A\mid z_t\}\): only \(z_t\) matters for predicting \(z_{t+1}\). This is what makes dynamic programming feasible — the current state is a sufficient statistic for future shocks. i.i.d. is the special case where \(Q(\cdot|z)\) does not depend on \(z\).

In the stochastic Bellman equation, what is the role of \(\beta\int V(x',z')Q(dz'|z)\)?

  • The period return from the shock \(z\) net of the investment cost
  • The deterministic continuation value evaluated at the optimal next state
  • The discounted expected continuation value over all possible next-period shocks
  • The value of holding the state fixed and waiting for a better shock
\(\beta\int V(x',z')Q(dz'|z)\) is the expected value of being in state \(x'\) next period, where the expectation is taken over all possible realizations of \(z'\) weighted by the transition probability \(Q(dz'|z)\), and discounted by \(\beta\). This is the stochastic analogue of the deterministic \(\beta V(x')\).

The Feller property of the transition kernel \(Q\) ensures what?

  • The stationary distribution of the Markov chain is unique
  • The optimal policy function is monotone in the shock \(z\)
  • The transition matrix has spectral radius strictly less than one
  • The expectation of a continuous function of the shock is continuous in the current shock
The Feller property says: if \(\phi\) is continuous and bounded, then \(z\mapsto E[\phi(z')|z]=\int\phi(z')Q(dz'|z)\) is also continuous in \(z\). This allows us to conclude that the value function \(V^*(x,z)\) is continuous in \(z\), which in turn is needed to apply the envelope theorem. Without Feller, continuity of the value function in \(z\) is not guaranteed.

The stochastic Euler equation differs from the deterministic Euler in that the right-hand side contains:

  • A conditional expectation \(E_t[\cdot]\) of the next-period marginal return
  • The maximized value of the Bellman equation at the next period's state
  • A costate variable for the resource constraint at each history
  • The variance of the marginal return as a risk adjustment
In the deterministic case, the Euler is \(0=F_y(x_t,x_{t+1})+\beta F_x(x_{t+1},x_{t+2})\) — no expectation. In the stochastic case, \(x_{t+2}\) is not known at date \(t\) (it depends on \(z_{t+1}\), which is realized between \(t\) and \(t+2\)), so the marginal return becomes a random variable and the condition involves its conditional expectation: \(0=F_y(x_t,x_{t+1},z_t)+\beta E_t[F_x(x_{t+1},x_{t+2},z_{t+1})]\).

10. True or False

True or False — justify in one or two lines
  1. An i.i.d. shock process is a special case of a first-order Markov process. Stoch p.3
    Answer

    True. An i.i.d. process has \(\Pr\{z_{t+1}\in A\mid z_t,\ldots\}=\Pr\{z_{t+1}\in A\}\), which is the same as \(Q(A\mid z)=Q(A)\) — a transition kernel that does not depend on the current state. This trivially satisfies the first-order Markov condition \(\Pr\{z_{t+1}\in A\mid z_t,\ldots\}=Q(A\mid z_t)\).

  2. The Principle of Optimality fails for stochastic problems, since the agent cannot foresee which history will be realized. Stoch p.11
    Answer

    False. The Principle of Optimality holds for stochastic problems under the same boundedness and existence conditions as the deterministic case. The key is that the value function \(V^*(x,z)\) is defined as the value of the optimal strategy from state \((x,z)\) — it already incorporates all future uncertainty. The fact that future shocks are unknown does not prevent the recursive characterization \(V^*=TV^*\); it just means the continuation value is an expected value rather than a certain value.

  3. The stochastic Euler equation must hold state-by-state: \(F_y(x_t,x_{t+1},z_t)+\beta F_x(x_{t+1},x_{t+2},z_{t+1})=0\) for every realization of \(z_{t+1}\). Stoch p.13
    Answer

    False. The stochastic Euler holds in conditional expectation: \(0=F_y(x_t,x_{t+1},z_t)+\beta E_t[F_x(x_{t+1},x_{t+2},z_{t+1})]\). It is an expectational condition, not a state-by-state condition. For a fixed realization \(z_{t+1}\), the expression inside the expectation will generally not be zero — the agent cannot perfectly equate marginal costs and benefits in each realization, only on average given current information.

  4. If the shock \(z\) is known to be constant forever (\(z_t=\bar z\) for all \(t\)), the stochastic Euler equation reduces to the deterministic Euler equation. Stoch p.13
    Answer

    True. When \(z_t=\bar z\) for all \(t\), the conditional expectation collapses to certainty: \(E_t[F_x(x_{t+1},x_{t+2},z_{t+1})]=F_x(x_{t+1},x_{t+2},\bar z)\). The stochastic Euler becomes \(0=F_y(x_t,x_{t+1},\bar z)+\beta F_x(x_{t+1},x_{t+2},\bar z)\), which is exactly the deterministic Euler equation with \(F(x,x')=F(x,x',\bar z)\). The stochastic and deterministic formulations are consistent.

11. Exercises

Exercise 43.1 Stoch p.5 (finite Markov chain)

Let \(Z=\{\zeta_1,\zeta_2\}\) with transition matrix \(P=\begin{pmatrix}p & 1-p\\ q & 1-q\end{pmatrix}\), \(p,q\in(0,1)\). Let \(\phi=(\phi_1,\phi_2)'\) be a function on \(Z\).

  1. Show that \(E[\phi(z_2)\mid z_0=\zeta_i]=[P^2\phi]_i\). (Hint: condition on \(z_1\) and apply the Markov property twice.) (10 pts)
  2. Find the stationary distribution \(\pi=(\pi_1,\pi_2)'\) satisfying \(\pi'P=\pi'\) and \(\pi_1+\pi_2=1\). (10 pts)
  3. What does \(E[\phi(z_t)\mid z_0=\zeta_1]\) converge to as \(t\to\infty\)? Under what condition on \(p\) and \(q\) does convergence occur? (5 pts)
Hint

For (a): \(E[\phi(z_2)|z_0=\zeta_i]=\sum_j E[\phi(z_2)|z_1=\zeta_j]P_{ij}=\sum_j [P\phi]_j P_{ij}=[P\cdot P\phi]_i=[P^2\phi]_i\). For (b): \(\pi'P=\pi'\) gives \(p\pi_1+q\pi_2=\pi_1\) (first component), so \((p-1)\pi_1+q\pi_2=0\), i.e. \(\pi_1/\pi_2=q/(1-p)\). For (c): a \(2\times2\) chain with \(p,q\in(0,1)\) is ergodic (irreducible and aperiodic), so \(P^t\to\mathbf{1}\pi'\) and \([P^t\phi]_i\to\pi'\phi=\pi_1\phi_1+\pi_2\phi_2\).

Show solution

(a) By the law of iterated expectations and the Markov property: $$E[\phi(z_2)|z_0=\zeta_i]=\sum_j E[\phi(z_2)|z_1=\zeta_j]\cdot\Pr\{z_1=\zeta_j|z_0=\zeta_i\}=\sum_j [P\phi]_j\cdot P_{ij}=[P^2\phi]_i.$$ By induction, \(E[\phi(z_t)|z_0=\zeta_i]=[P^t\phi]_i\). \(\square\)

(b) \(\pi'P=\pi'\) with \(\pi_1+\pi_2=1\). From row 1: \(p\pi_1+(1-q)\pi_2=\pi_2\implies p\pi_1=q\pi_2\implies\pi_1/\pi_2=q/p\). Wait, more carefully: \(p\pi_1+q\pi_2=\pi_1\implies(p-1)\pi_1=-q\pi_2\implies(1-p)\pi_1=q\pi_2\). With \(\pi_1+\pi_2=1\): \(\pi_1=q/(1-p+q)\) and \(\pi_2=(1-p)/(1-p+q)\). Check: \(\pi_1+\pi_2=[q+(1-p)]/(1-p+q)=1\). \(\square\)

(c) When \(p,q\in(0,1)\), the chain is irreducible (can transition between both states in one step) and aperiodic (stays in state 1 with probability \(p>0\)). By the ergodic theorem, \([P^t\phi]_i\to\pi_1\phi_1+\pi_2\phi_2\) for all starting states \(i\). So \(E[\phi(z_t)|z_0=\zeta_1]\to\pi_1\phi_1+\pi_2\phi_2=\frac{q\phi_1+(1-p)\phi_2}{1-p+q}\). Convergence fails if \(p=1\) and \(q=1\) (absorbing states without reaching the other) or if the chain is periodic.

  4. Suppose the shock \(z_{t+1}=z_t=1\) but the agent incorrectly believes \(z_{t+1}\) is random. Does the optimal policy change? Why or why not? (5 pts)
Hint

For (b): with \(F_y(k,k',z)=-U'(zf(k)-k')\) and \(F_x(k,k',z)=U'(zf(k)-k')zf'(k)\), the stochastic Euler becomes \(U'(c_t)=\beta E_t[U'(c_{t+1})z_{t+1}f'(k_{t+1})]\). For (c): with no uncertainty, \(E_t[\cdot]\) is just the value at \(z_{t+1}=z\), and the Euler becomes the standard deterministic condition.

Show solution

(a) State space: \((k,z)\in\mathbb R_+\times Z\). Choice: \(k'\in[0,zf(k)]\). Bellman equation: $$V(k,z)=\max_{k'\in[0,zf(k)]}\left\{U(zf(k)-k')+\beta\int V(k',z')\,Q(dz'\mid z)\right\}.$$

(b) With \(c_t=z_t f(k_t)-k_{t+1}\): \(F_y(k,k',z)=\partial U(zf(k)-k')/\partial k'=-U'(c)\) and \(F_x(k,k',z)=U'(c)\cdot zf'(k)\). The stochastic Euler: $$0=-U'(c_t)+\beta E_t[U'(c_{t+1})z_{t+1}f'(k_{t+1})],$$ $$\text{i.e.,}\quad U'(c_t)=\beta E_t\bigl[U'(c_{t+1})\cdot z_{t+1}f'(k_{t+1})\bigr].$$ Left side: marginal utility of consuming one more unit today. Right side: expected discounted marginal utility of investing one unit (which produces \(z_{t+1}f'(k_{t+1})\) units tomorrow). At the optimum these are equal.

(c) With \(z_{t+1}=z\) for all \(t\): the expectation collapses, \(E_t[U'(c_{t+1})zf'(k_{t+1})]=U'(c_{t+1})zf'(k_{t+1})\), and the Euler becomes \(U'(c_t)=\beta U'(c_{t+1})zf'(k_{t+1})\). This is exactly the deterministic Euler equation with \(F(k,k')=U(zf(k)-k')\). The two formulations are consistent.

(d) If \(z_{t+1}=1\) always but the agent believes it is random, the agent's perceived Euler equation involves an expectation, but since \(z_{t+1}=1\) is known with certainty (the agent just doesn't know it), the expectation equals the realized value. The optimal policy is therefore the same as if the agent knew \(z=1\). The mistake in beliefs does not affect outcomes when the perceived uncertainty turns out to be zero; the policies "happen to coincide". This is a special case of certainty equivalence (which will be studied in Lesson 44).

Exercise 43.3 Proof (stochastic envelope theorem)

Prove the envelope condition \(V_x(x,z)=F_x(x,g(x,z),z)\) in the stochastic case by differentiating the Bellman equation with respect to \(x\) and applying the first-order condition.

  1. Write the Bellman equation \(V(x,z)=F(x,g(x,z),z)+\beta\int V(g(x,z),z')\,Q(dz'\mid z)\). Differentiate both sides with respect to \(x\). (5 pts)
  2. Your expression from (a) should contain a term involving \(g'(x)\) (the derivative of the optimal policy with respect to the current state). Write out this term. (5 pts)
  3. Apply the FOC \(0=F_y(x,g(x,z),z)+\beta\int V_x(g(x,z),z')\,Q(dz'\mid z)\) to show that the terms multiplied by \(g'(x)\) sum to zero. Conclude that \(V_x(x,z)=F_x(x,g(x,z),z)\). (10 pts)
Hint

Differentiating \(F(x,g(x,z),z)\) with respect to \(x\) gives \(F_x+F_y g'(x)\). Differentiating \(\beta\int V(g(x,z),z')Q(dz'|z)\) with respect to \(x\) gives \(\beta\int V_x(g(x,z),z')Q(dz'|z)\cdot g'(x)\). Both terms contain \(g'(x)\), and their coefficient is exactly the FOC (which equals zero).

Show solution

(a) Differentiating both sides of the Bellman equation \(V(x,z)=F(x,g(x,z),z)+\beta\int V(g(x,z),z')Q(dz'|z)\) with respect to \(x\):

$$V_x(x,z)=F_x(x,g(x,z),z)+F_y(x,g(x,z),z)\cdot g'(x)+\beta\int V_x(g(x,z),z')\,Q(dz'\mid z)\cdot g'(x).$$

(b) The terms involving \(g'(x)\) are:

$$g'(x)\cdot\left[F_y(x,g(x,z),z)+\beta\int V_x(g(x,z),z')\,Q(dz'\mid z)\right].$$

(c) The first-order condition for the maximization in the Bellman equation is exactly:

$$0=F_y(x,g(x,z),z)+\beta\int V_x(g(x,z),z')\,Q(dz'\mid z).$$

Therefore the bracket in (b) equals zero, and the \(g'(x)\) terms cancel:

$$V_x(x,z)=F_x(x,g(x,z),z).\quad\square$$

Note: this argument requires \(g\) to be differentiable with respect to \(x\), which follows from the differentiability of \(F\) and the implicit function theorem under standard conditions (the same conditions needed for the Benveniste–Scheinkman theorem in the deterministic case).

Key takeaways

  • A first-order Markov process \(\{z_t\}\) is characterized by a transition kernel \(Q(dz'|z)\): the distribution of \(z_{t+1}\) given \(z_t=z\). For finite \(Z\), \(Q\) is a row-stochastic matrix \(P\). For continuous \(Z\), a leading case is \(z_{t+1}=\mu(z_t)+\sigma(z_t)e_{t+1}\) with i.i.d. innovations.
  • The stochastic Bellman operator is \((TV)(x,z)=\max_{x'\in\Gamma(x,z)}\{F(x,x',z)+\beta\int V(x',z')Q(dz'|z)\}\). Under standard conditions, \(T\) is a contraction and its unique fixed point is the optimal value function \(V^*\).
  • The Feller property (\(Q\) maps continuous functions to continuous functions) is needed to establish continuity of \(V^*\) in \(z\). First-order stochastic dominance of \(Q\) in \(z\) gives monotonicity of \(V^*\) in \(z\).
  • The stochastic envelope condition is \(V_x(x,z)=F_x(x,g(x,z),z)\): the same form as the deterministic Benveniste–Scheinkman theorem. Proof: differentiate the Bellman equation; the \(g'(x)\) terms cancel by the FOC.
  • The stochastic Euler equation is \(0=F_y(x_t,x_{t+1},z_t)+\beta E_t[F_x(x_{t+1},x_{t+2},z_{t+1})]\): the same optimality tradeoff as the deterministic case, but now the marginal benefit of investing is taken in conditional expectation over all future realizations of \(z_{t+1}\).
  • The stochastic transversality condition requires \(\beta^T E_0[F_x(x_T,x_{T+1},z_T)\cdot x_T]\to0\): the present-value shadow price of the state times the state must vanish. This rules out "oversaving" paths. It requires additional regularity (integrability, admissibility) beyond the deterministic case.

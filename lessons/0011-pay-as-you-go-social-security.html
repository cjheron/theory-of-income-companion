Pay-As-You-Go Social Security

Covers Class Note II, pp. 19–20 · About 30 min · Prerequisite: Lesson 10
By the end you can:
  1. model a pay-as-you-go (PAYG) social security system as a change in after-tax endowments, and solve for the new CE;
  2. find the tax \(\tau^* = \beta-\alpha\) that implements the best symmetric allocation;
  3. answer the slide question: for which parameters, and for which taxes \(\tau\), does social security produce a CE that Pareto-dominates the original one? Answer: iff \(\bar r<0\), and then for every \(\tau\in(0,\bar\tau]\).
Primary source Alvarez, Class Note II, pp. 19–20. Samuelson's 1958 paper makes the same point with a "social compact" and with fiat money. Exercise 11.6 shows that the two are equivalent. Diamond, "National Debt in a Neoclassical Growth Model", AER (1965), extends the argument to an economy with capital (see Lesson 15).

1. The policy

Definition: PAYG social security with tax \(\tau\) II p.19

At every date, each young agent pays a lump-sum tax \(\tau\) and each old agent alive receives a transfer \(\tau\). One young and one old are alive at each date, so taxes equal transfers period by period: the government budget balances for every \(\tau\) and the government never issues debt. After-tax endowments become $$e^i_i = (1-\alpha)-\tau,\qquad e^i_{i+1} = \alpha+\tau\quad (i\ge1),\qquad e^0_1 = \alpha+\tau .$$ We need \(\tau<1-\alpha\) so that young endowments stay positive. A negative \(\tau\) is a transfer from old to young.

"Pay-as-you-go" means that current workers' contributions are paid out immediately to current retirees. Nothing is invested. Contrast this with a funded system that would save contributions and pay retirees out of the accumulated returns; Lesson 14 shows how to move between the two.

2. The equilibrium with social security

The policy only relabels endowments. Every assumption of the no-trade proposition (Lesson 8) still holds with the after-tax endowments, so the unique CE is again autarky, now at the after-tax point:

$$c_y(\tau) = 1-\alpha-\tau,\qquad c_o(\tau) = \alpha+\tau .$$

The equilibrium interest rate follows from Lesson 9's formula evaluated at the new endowment:

$$1+r(\tau) = \frac{v_1}{v_2}\Big|_{(1-\alpha-\tau,\ \alpha+\tau)} = \frac{(1-\beta)(\alpha+\tau)}{\beta(1-\alpha-\tau)},$$

which is increasing in \(\tau\). Social security shifts resources toward old age, so the young want to save less. To keep them content with zero savings, the interest rate must rise.

Implementing the best symmetric allocation

Choosing \(\tau\) so that the after-tax endowment is \((1-\beta,\beta)\) requires II p.19

$$\boxed{\;\tau^* = \beta-\alpha\;}$$

and then \(1+r(\tau^*) = \frac{(1-\beta)\beta}{\beta(1-\beta)} = 1\): the interest rate becomes zero, the biological rate of return.

3. When does social security make everyone better off?

Compare the CE with policy \(\tau\) to the CE without it (\(\tau=0\)).

  • Initial old: consumption \(\alpha+\tau\). They gain iff \(\tau>0\).
  • Generations \(i\ge1\): utility \(W(\tau) \equiv (1-\beta)\log(1-\alpha-\tau) + \beta\log(\alpha+\tau)\).
Analysis of \(W(\tau)\)
  1. Strict concavity. \(W''(\tau) = -\frac{1-\beta}{(1-\alpha-\tau)^2} - \frac{\beta}{(\alpha+\tau)^2} < 0\).
  2. Peak. \(W'(\tau) = -\frac{1-\beta}{1-\alpha-\tau} + \frac{\beta}{\alpha+\tau} = 0\) at \(\alpha+\tau = \beta\), i.e. at \(\tau^*=\beta-\alpha\).
  3. Slope at zero. \(W'(0) = \frac{\beta}{\alpha} - \frac{1-\beta}{1-\alpha} = \frac{1-\beta}{1-\alpha}\Big[\frac{1}{1+\bar r}-1\Big]\). This is positive iff \(\bar r<0\) iff \(\beta>\alpha\). A small PAYG system is a "bond" paying a gross return of 1. The young value it at \(1/(1+\bar r)\), which exceeds 1 exactly when \(\bar r<0\).
  4. Case \(\beta>\alpha\). \(W\) rises on \([0,\tau^*]\) and falls after, with \(W\to-\infty\) as \(\tau\uparrow1-\alpha\). By continuity there is a unique \(\bar\tau\in(\tau^*,1-\alpha)\) with \(W(\bar\tau)=W(0)\). Hence \(W(\tau)\ge W(0)\iff\tau\in[0,\bar\tau]\).
  5. Case \(\beta\le\alpha\). \(\tau^*\le0\), so \(W\) is strictly decreasing on \([0,1-\alpha)\). Any \(\tau>0\) hurts generations \(i\ge1\), and any \(\tau<0\) hurts the initial old. No \(\tau\ne0\) is a Pareto improvement.
∎
Answer to the slide question II p.20

A PAYG system with tax \(\tau\) yields a CE that Pareto-dominates the no-policy CE if and only if \(\beta>\alpha\), equivalently the no-policy CE has a negative interest rate \(\bar r<0\), and \(\tau\in(0,\bar\tau]\), where \(\bar\tau>\beta-\alpha\) solves $$(1-\beta)\log\frac{1-\alpha-\bar\tau}{1-\alpha} + \beta\log\frac{\alpha+\bar\tau}{\alpha} = 0 .$$ At \(\tau=\bar\tau\) the young are exactly indifferent, but the initial old strictly gain, so it is still a Pareto improvement. The improvement is largest for the young at \(\tau^*=\beta-\alpha\). If \(\beta=\tfrac12\), then \(W\) is symmetric around \(\tau^*\) and \(\bar\tau = 2(\beta-\alpha)\) exactly. Otherwise \(\bar\tau\gtrless2(\beta-\alpha)\) as \(\beta\lessgtr\tfrac12\) (Exercise 11.3).

Orange is the no-policy CE, blue is the best symmetric point. Right: welfare changes relative to \(\tau=0\): blue is \(W(\tau)-W(0)\) for every generation \(i\ge1\); orange is the initial old's gain \(\tau\). The two are in different units (utils vs. goods), so only their signs matter for Pareto comparisons. The aqua band on the axis is the Pareto-improving set \((0,\bar\tau]\). Try: lower \(\beta\) below \(\alpha\) and watch the band disappear, as the blue curve now peaks at a negative \(\tau\).
Intuition: PAYG is an asset with return equal to population growth

From any generation's point of view, PAYG says: give up \(\tau\) when young, get \(\tau\) when old. That's a savings instrument with a gross return of \(1\), the ratio of contributors to recipients. Private markets offered an "autarky" return \(1+\bar r\). If \(1+\bar r<1\), the PAYG asset dominates and everyone wants some. The initial old receive a pure windfall. The scheme's "capital" is the promise that the next young will pay, and that promise is honoured forever. In Lesson 13 the return on PAYG becomes \((1+n)(1+g)\) and the condition becomes \(1+\bar r<(1+n)(1+g)\).

4. Check your understanding

1. What is the CE allocation once PAYG social security with tax \(\tau\) is introduced?
  • The best symmetric allocation, for any positive tax τ
  • The original endowment, since taxes cancel out exactly
  • Autarky at the after-tax endowment (1−α−τ, α+τ)
  • Whatever allocation sets the interest rate equal to zero
The no-trade proposition applies to any positive endowments, including after-tax ones. So consumption equals after-tax endowment. Only at \(\tau=\beta-\alpha\) is this the best symmetric allocation, and only then is \(r=0\).
2. Why does a small PAYG system benefit generations \(i\ge1\) exactly when \(\bar r<0\)?
  • It pays a zero net return, beating the market rate r̄
  • It lowers taxes on the young below the transfer to the old
  • It raises aggregate endowment above one in every period
  • It eliminates the initial old, who were the binding agents
\(W'(0) = \frac{1-\beta}{1-\alpha}\big[\frac1{1+\bar r}-1\big]\). The marginal value of a unit received when old, relative to a unit paid when young, is \(1/(1+\bar r)\). PAYG trades them one-for-one, so it helps iff \(1/(1+\bar r)>1\).
3. With \(\beta>\alpha\), which taxes \(\tau\) give a Pareto improvement over the no-policy CE?
  • Only the single tax τ = β − α, and no other value
  • Every tax τ between zero and one minus α, inclusive
  • Every tax τ between zero and 2(β − α), for any β
  • Every tax in (0, τ̄], where young utility returns to CE
The initial old gain for any \(\tau>0\). The young weakly gain on \([0,\bar\tau]\) by concavity of \(W\). \(\bar\tau\) equals \(2(\beta-\alpha)\) only in the special case \(\beta=1/2\).
4. Social security is in place with \(\tau=\tau^*\). The government abolishes it at date \(T\). Who loses?
  • Generation T, since it never pays the tax when young
  • Generation T − 1, which paid when young but gets nothing
  • Nobody, since the government budget always balanced
  • The initial old, since the scheme retroactively unwinds
Generation \(T-1\) paid \(\tau^*\) at \(T-1\) and expected \(\tau^*\) at \(T\). Abolition leaves it with \((1-\beta,\alpha)\), worse than both the CE and the best allocation. Generation \(T\) returns to autarky, and earlier generations are unaffected. The chain must never be broken.

5. Exercises

Exercise 11.1 Slides p.20

Answer the slide question in full: (a) under what parameter values does the PAYG policy produce a CE that Pareto-dominates the CE without the policy? (b) What interest rate must the CE without policy have? (c) Does it matter whether the tax is \(\tau^*\) or some other positive number?

Show solution

(a) \(\beta>\alpha\) (Case 1 of Lesson 10). (b) \(\bar r<0\). (c) Yes: \(\tau\) must lie in \((0,\bar\tau]\). Any such \(\tau\) works, and \(\tau^*=\beta-\alpha\) is the best one for generations \(i\ge1\). Too large a tax (\(\tau>\bar\tau\)) over-saves on the young's behalf and makes them worse off than in autarky, even though the initial old still gain. See the analysis in §3 for the proof.

Exercise 11.2 Exam-style

Let \(\alpha=0.2\), \(\beta=0.4\).

  1. Compute the no-policy interest rate \(\bar r\).
  2. Compute the interest rate in the CE with \(\tau = 0.1\).
  3. Compute \(\bar\tau\) numerically (you may use the figure).
Show solution

(a) \(\bar r = -0.2/0.32 = -0.625\). (b) \(1+r = \frac{0.6\cdot0.3}{0.4\cdot0.7} = 0.643\), so \(r\approx-0.357\). The rate rises toward 0 as \(\tau\to\tau^*=0.2\). (c) Solve \(0.6\log\frac{0.8-\tau}{0.8} + 0.4\log\frac{0.2+\tau}{0.2}=0\) on \((0.2,0.8)\): \(\bar\tau\approx0.426\), slightly above \(2(\beta-\alpha)=0.4\).

Exercise 11.3 Proof

Show that when \(\beta=\tfrac12\), \(\bar\tau = 2(\beta-\alpha) = 1-2\alpha\). Then show that, more generally, \(\bar\tau>2(\beta-\alpha)\) if \(\beta<\tfrac12\) and \(\bar\tau<2(\beta-\alpha)\) if \(\beta>\tfrac12\).

Hint

Write young utility as a function of old-age consumption \(c\): \(f(c) = (1-\beta)\log(1-c) + \beta\log c\), with peak at \(c=\beta\). With \(d\equiv\beta-\alpha>0\), the CE is at \(c = \beta-d\), and \(\tau=2d\) puts the young at \(c=\beta+d\). Study \(g(d)\equiv f(\beta+d)-f(\beta-d)\).

Show solution
  1. Reduction. \(\bar\tau\) is where \(f\) returns to its CE level \(f(\beta-d)\) on the far side of the peak. Since \(f\) is strictly decreasing to the right of \(\beta\): \(\bar\tau > 2d \iff f(\beta+d) > f(\beta-d) \iff g(d) > 0\), and \(\bar\tau = 2d\iff g(d)=0\).
  2. Derivative. \(g(0)=0\) and \(g'(d) = f'(\beta+d)+f'(\beta-d)\). Using \(f'(c) = \frac{\beta}{c}-\frac{1-\beta}{1-c}\): $$g'(d) = \beta\Big[\tfrac{1}{\beta+d}+\tfrac{1}{\beta-d}\Big] - (1-\beta)\Big[\tfrac{1}{1-\beta-d}+\tfrac{1}{1-\beta+d}\Big] = \frac{2\beta^2}{\beta^2-d^2} - \frac{2(1-\beta)^2}{(1-\beta)^2-d^2}.$$
  3. Sign. \(h(x) = \frac{x^2}{x^2-d^2} = 1 + \frac{d^2}{x^2-d^2}\) is strictly decreasing in \(x>d\). So \(g'(d)>0\iff h(\beta)>h(1-\beta)\iff\beta<1-\beta\iff\beta<\tfrac12\). For \(\beta=\tfrac12\), \(g'\equiv0\).
  4. Conclusion. Integrating from \(g(0)=0\): if \(\beta=\tfrac12\), \(g\equiv0\) and \(\bar\tau = 2d = 1-2\alpha\) (indeed \(f(c)=\tfrac12\log(c(1-c))\) is symmetric about \(\tfrac12\)). If \(\beta<\tfrac12\), \(g(d)>0\) and \(\bar\tau>2(\beta-\alpha)\). If \(\beta>\tfrac12\), \(g(d)<0\) and \(\bar\tau<2(\beta-\alpha)\). (Here \(d\) ranges over values with \(\beta+d<1\), which holds whenever \(\beta<\tfrac12\). If \(\beta+d\ge1\), then \(\tau=2d\) is infeasible and \(\bar\tau<2d\) trivially.)

Numerical check: \((\alpha,\beta) = (0.2,0.4)\) gives \(\bar\tau = 0.426 > 0.4\); \((0.3,0.5)\) gives exactly \(0.4\); \((0.5,0.7)\) gives \(0.358<0.4\). Try them in the figure.

Exercise 11.4 Exam-style (transitions)

Suppose \(\beta>\alpha\). (a) The government introduces PAYG with \(\tau^*\) at date \(T>1\), not date 1. Rank every generation's welfare relative to the no-policy CE. (b) It instead introduces it at date 1 and abolishes it at date \(T\). Rank again. (c) What does this say about the political economy of PAYG systems?

Show solution

(a) Generations \(0,\dots,T-2\) are unaffected (autarky). Generation \(T-1\) is the "initial old" of the new system: it gets \(\tau^*\) for free when old and strictly gains. Generations \(\ge T\) pay and receive \(\tau^*\) and strictly gain. Pareto improvement.

(b) Generations \(0,\dots,T-2\) strictly gain. Generation \(T-1\) pays \(\tau^*\) when young and receives nothing when old: it consumes \((1-\beta,\alpha)\) and strictly loses relative to the CE. Generations \(\ge T\) are back to autarky and unaffected. Not a Pareto improvement.

(c) Introducing PAYG creates a windfall for the generation that is old at introduction, and abolishing it imposes a loss on the generation that is old at abolition. Every generation has an incentive to keep the system going. In the inefficient case, PAYG is a self-sustaining "social compact" (Samuelson's phrase).

Exercise 11.5 Exam-style

Now take \(\beta<\alpha\) (so \(\bar r>0\)). (a) Show that a negative \(\tau\) (old-to-young transfers) raises the utility of every generation \(i\ge1\) for small \(|\tau|\). (b) Why is this nevertheless not a Pareto improvement? (c) Would it be one if the economy started at date \(-\infty\), with no initial old?

Show solution

(a) \(W'(0) = \frac{1-\beta}{1-\alpha}\big[\frac1{1+\bar r}-1\big]<0\) when \(\bar r>0\), so lowering \(\tau\) below 0 raises \(W\).

(b) The initial old's consumption falls to \(\alpha+\tau<\alpha\). Someone loses.

(c) With a doubly-infinite time line \(t\in\mathbb{Z}\), there is no initial old. Every generation is both a payer and a receiver, so \(\tau<0\) would make everyone better off when \(\bar r>0\) (and \(\tau>0\) when \(\bar r<0\)). The asymmetry between Cases 1 and 3 comes entirely from having a beginning without an end. (Shell 1971 discusses such "doubly infinite" economies.)

Exercise 11.6 Exam-style (fiat money)

Remove social security. Instead, at date 1 the initial old hold \(M>0\) units of intrinsically useless fiat money. Each period the young may buy money from the old at price \(1/P_t\) (goods per unit of money) and sell it when old. (a) Write generation \(t\)'s budget constraints and show that the gross real return on money is \(P_t/P_{t+1}\). (b) Look for a stationary monetary equilibrium with \(P_t = P\). Find real balances \(M/P\) and consumption. (c) When does such an equilibrium exist? Compare with the PAYG system.

Show solution

(a) Young: \(c_y + m_t/P_t = 1-\alpha\). Old: \(c_o = \alpha + m_t/P_{t+1}\). Real savings \(s_t = m_t/P_t\) earn gross return \(P_t/P_{t+1}\).

(b) With constant \(P\) the return is 1, i.e. \(r=0\). Money-market clearing requires the young to hold all money, \(m_t=M\), so \(M/P = s(0) = \beta(1-\alpha)-(1-\beta)\alpha = \beta-\alpha\). Consumption is \(c_y = 1-\alpha-(\beta-\alpha) = 1-\beta\) and \(c_o = \beta\), with the initial old consuming \(\alpha + M/P = \beta\).

(c) It requires \(M/P>0\), i.e. \(\beta>\alpha\), exactly when \(\bar r<0\). The allocation is identical to PAYG with \(\tau^*\). Valued fiat money is a privately-sustained version of social security: each young generation "pays" the old for money and is "repaid" by the next young. This is Samuelson's "social contrivance of money".

Key takeaways

  • PAYG with tax \(\tau\) relabels endowments to \((1-\alpha-\tau,\alpha+\tau)\). The new CE is autarky there, with \(1+r(\tau) = \frac{(1-\beta)(\alpha+\tau)}{\beta(1-\alpha-\tau)}\).
  • \(\tau^*=\beta-\alpha\) implements the best symmetric allocation and drives \(r\) to 0.
  • PAYG Pareto-improves iff \(\bar r<0\) (\(\beta>\alpha\)), and then for every \(\tau\in(0,\bar\tau]\), where \(W(\bar\tau)=W(0)\).
  • PAYG is an asset with return equal to population growth (here 0). It beats markets when \(\bar r\) is below that. Valued fiat money does the same job.

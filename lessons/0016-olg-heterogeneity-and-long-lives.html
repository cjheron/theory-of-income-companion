Heterogeneity and Long Lives in the OLG Model

Covers Class Note III, pp. 20–24 · About 35 min · Prerequisites: Lesson 10, Lesson 11
By the end you can:
  1. derive each type's consumption under log utility and show that the equilibrium interest rate depends on the distribution of endowments only through the mean \(\bar\alpha\);
  2. construct a feasible allocation that Pareto-dominates the equilibrium when \(\bar\alpha<\beta\), and verify both properties;
  3. show with numbers that a uniform PAYG system can hurt some types even though the economy is dynamically inefficient;
  4. prove that with \(N\)-period lives and negative interest rates, a small transfer from younger to older ages is a Pareto improvement.
Primary source Alvarez, Class Note III, pp. 20–24. Samuelson's original consumption-loan model actually has three-period lives, and its argument is the ancestor of §4: Samuelson, P. (1958), “An Exact Consumption-Loan Model of Interest with or without the Social Contrivance of Money,” JPE 66(6): 467–482.
Notation alert

The heterogeneity slides return to the Class Note II convention: young endowment \(1-\alpha_n\), old endowment \(\alpha_n\). This is the reverse of the privatization slides (Lesson 14), where young had \(\alpha\). Here \(\alpha\) is an endowment share again, not the capital share of Lesson 15. Preferences are \((1-\beta)\log c_y + \beta\log c_o\) for every type.

1. Heterogeneity within a generation

Each generation has \(N\) types \(n=1,\dots,N\), each of mass \(1/N\), so total population per generation is 1. Type \(n\) has endowments \(e^{t,n}_t = 1-\alpha_n\) when young and \(e^{t,n}_{t+1} = \alpha_n\) when old III p.20. Define the average old-age endowment

$$\bar\alpha = \frac1N\sum_{n=1}^N \alpha_n .$$

The aggregate endowment per period is still \(\frac1N\sum_n(1-\alpha_n) + \frac1N\sum_n\alpha_n = 1\).

Individual demands

  1. Lifetime wealth of a type-\(\alpha\) agent at interest rate \(r\): \(W(\alpha,r) = (1-\alpha) + \dfrac{\alpha}{1+r}\).
  2. Log utility spends fixed shares of wealth: \(c_y = (1-\beta)W\) and \(c_o/(1+r) = \beta W\). So $$c_y(\alpha,r) = (1-\beta)\Big[(1-\alpha) + \frac{\alpha}{1+r}\Big], \qquad c_o(\alpha,r) = \beta\big[(1+r)(1-\alpha) + \alpha\big].$$
  3. Ratio across types. Both consumptions are proportional to \(W\), so $$\frac{c_y(\alpha,r)}{c_y(\bar\alpha,r)} = \frac{c_o(\alpha,r)}{c_o(\bar\alpha,r)} = \frac{W(\alpha,r)}{W(\bar\alpha,r)} = \frac{(1+r)(1-\alpha)+\alpha}{(1+r)(1-\bar\alpha)+\bar\alpha} = \frac{1+(1-\alpha)r}{1+(1-\bar\alpha)r} .$$

Every type chooses the same shape of lifetime consumption, the bundle of a hypothetical average type scaled up or down by relative wealth.

Aggregation and the interest rate

Saving of type \(\alpha\) is

$$s(\alpha,r) = (1-\alpha) - c_y(\alpha,r) = \beta(1-\alpha) - (1-\beta)\frac{\alpha}{1+r},$$

which is the same formula as in Lesson 9 and is linear in \(\alpha\). Averaging a linear function gives the function at the average: \(\frac1N\sum_n s(\alpha_n,r) = s(\bar\alpha,r)\). Equilibrium requires zero aggregate saving (there is no asset in positive net supply), so III p.21

$$s(\bar\alpha,\bar r) = 0 \quad\Longleftrightarrow\quad \bar r = \frac{\bar\alpha-\beta}{\beta(1-\bar\alpha)} .$$

This is the homogeneous-economy interest rate with \(\alpha=\bar\alpha\). In particular, \(\bar r<0\) iff \(\bar\alpha<\beta\).

One big difference: now there is trade

In the homogeneous economy the equilibrium was autarky (Lesson 8). Here only aggregate saving is zero. Types with \(\alpha_n<\bar\alpha\) (poor when old) save, \(s>0\), and types with \(\alpha_n>\bar\alpha\) borrow from them. Young agents trade with each other in a within-generation credit market. The old still cannot trade with the young, since nobody would lend to someone about to die.

2. The equilibrium is still inefficient when \(\bar\alpha<\beta\)

The best aggregate symmetric allocation is \(c_y^* = 1-\beta\), \(c_o^*=\beta\), as before. The slides III p.21 propose distributing it across types in proportion to equilibrium wealth:

The rescaled allocation

Let \(\lambda_n \equiv \dfrac{1+(1-\alpha_n)\bar r}{1+(1-\bar\alpha)\bar r}\). Give every young type-\(n\) agent \(\big(\lambda_n(1-\beta),\ \lambda_n\beta\big)\) over its life, and give every initial-old type-\(n\) agent \(\alpha_n + (\beta-\bar\alpha)\).

Claim

If \(\bar\alpha<\beta\), the rescaled allocation is feasible and Pareto-dominates the competitive equilibrium.

Proof
  1. The weights average to one. \(\lambda_n\) is linear in \(\alpha_n\), so \(\frac1N\sum_n\lambda_n = \dfrac{1+(1-\bar\alpha)\bar r}{1+(1-\bar\alpha)\bar r} = 1\).
  2. Feasibility at \(t\ge2\). Average young consumption plus average old consumption is \((1-\beta)\cdot 1 + \beta\cdot 1 = 1\), the aggregate endowment.
  3. Feasibility at \(t=1\). The initial old consume on average \(\bar\alpha + \beta - \bar\alpha = \beta\), and the young of generation 1 consume \(1-\beta\) on average. The total is 1.
  4. The CE bundle of type \(n\) is \(\lambda_n\) times the average type's. By the ratio formula, type \(n\) consumes \(\lambda_n\big(c_y(\bar\alpha,\bar r), c_o(\bar\alpha,\bar r)\big)\). At \(\bar r\) the average type saves zero, so its bundle is its endowment \((1-\bar\alpha,\bar\alpha)\). Type \(n\)'s CE bundle is therefore \(\lambda_n(1-\bar\alpha,\bar\alpha)\).
  5. Young generations gain. With log utility, \(v(\lambda c_y,\lambda c_o) = \log\lambda + v(c_y,c_o)\). So type \(n\)'s gain is \(v(1-\beta,\beta) - v(1-\bar\alpha,\bar\alpha)\), the same for every type. It is strictly positive, because \((1-\beta,\beta)\) uniquely maximizes \(v\) on \(c_y+c_o=1\) and \(\bar\alpha\ne\beta\).
  6. Initial old gain. In the CE they consume \(\alpha_n\) (nothing to trade). Now they get \(\alpha_n + \beta-\bar\alpha > \alpha_n\) since \(\bar\alpha<\beta\).
∎

So heterogeneity does not remove the negative-interest-rate inefficiency. But notice how carefully the improvement had to be constructed: each type's share \(\lambda_n\) depends on its own \(\alpha_n\).

3. A uniform PAYG system is not enough

Now suppose the government uses the simple tool of Lesson 11: every young person pays \(\tau\) and every old person receives \(\tau\) III p.22. After-tax endowments become \(1-\alpha_n-\tau\) and \(\alpha_n+\tau\), so the average old endowment rises to \(\bar\alpha+\tau\) and

$$r(\tau) = \frac{\bar\alpha+\tau-\beta}{\beta(1-\bar\alpha-\tau)}, \qquad \text{increasing in } \tau .$$

With log utility, type \(n\)'s equilibrium utility is (up to a constant common to all types)

$$U_n(\tau) = \log W_n(\tau) + \beta\log\big(1+r(\tau)\big), \qquad W_n(\tau) = (1-\alpha_n-\tau) + \frac{\alpha_n+\tau}{1+r(\tau)} .$$

(Plug \(c_y=(1-\beta)W\) and \(c_o=\beta(1+r)W\) into \(v\).) A higher \(r\) helps lenders and hurts borrowers. The types with high \(\alpha_n\) are borrowers, and the policy destroys their cheap credit.

Worked example

\(\beta = 0.5\), two equal-sized types with \(\alpha_1 = 0.05\) and \(\alpha_2 = 0.55\), so \(\bar\alpha = 0.3<\beta\).

  1. \(\bar r = (0.3-0.5)/(0.5\cdot 0.7) = -4/7\approx -0.571\), so \(1+\bar r = 3/7\). Type 1 saves \(s_1 = 0.5(0.95) - 0.5(0.05)(7/3) \approx 0.417\); type 2 borrows \(s_2\approx -0.417\).
  2. Choose \(\tau = \beta-\bar\alpha = 0.2\). Then \(\bar\alpha+\tau=\beta\), so \(r(\tau) = 0\), \(W_n = 1\) and \(U_n = 0\) for both types.
  3. Before the policy: \(U_1 = \log(0.95 + 0.05\cdot\tfrac73) + 0.5\log\tfrac37 \approx 0.0645 - 0.4236 = -0.359\), and \(U_2 = \log(0.45 + 0.55\cdot\tfrac73) + 0.5\log\tfrac37 \approx 0.550 - 0.424 = +0.126\).
  4. Type 1 gains 0.359; type 2 loses 0.126. The uniform PAYG system is not a Pareto improvement, even though the rescaled allocation of §2 gives both types a gain of \(v(0.5,0.5)-v(0.7,0.3)\approx 0.087\).

The orange line is the gain from the rescaled allocation of §2, which is the same for every type and exists only when \(\bar\alpha<\beta\). Then set \(\bar\alpha>\beta\): now \(\bar r>0\), the orange line disappears, and borrowers still lose. No allocation can help everyone, because the First Welfare Theorem applies.
Lesson from the slides III p.22

Correcting aggregate dynamic inefficiency, i.e. raising \(r\) toward the growth rate, is one problem. Distributing the gains so that nobody loses is a second one. A uniform tax solves the first but not the second, because it changes a relative price, \(r\), at which heterogeneous agents are on opposite sides of the market. Exercise 16.4 shows that adding within-generation lump-sum transfers fixes the second problem.

4. Agents who live \(N\) periods

Now return to a single type per generation, but let each generation live \(N\ge2\) periods III p.23. Generation \(t\) has utility \(u^t = v^t(c^t_t,\dots,c^t_{t+N-1})\), and at every date one generation of each age \(a=1,\dots,N\) is alive. At the equilibrium allocation \(\bar c^t\), the first-order conditions are

$$v^t_a(\bar c^t) = \lambda^t p_{t+a-1}, \qquad a = 1,\dots,N,$$

where \(v^t_a\) is the marginal utility of consumption at age \(a\), \(\lambda^t>0\) is the multiplier on the budget, and \(p_s\) is the date-\(s\) price.

The "young-to-old" transfer \((\tau, Y)\)

Fix \(Y

Claim III p.24

In the pure-exchange economy, if all equilibrium interest rates are negative, then for \(\tau>0\) small enough the transfer \((\tau,Y)\) Pareto-dominates the equilibrium allocation.

Proof
  1. Feasibility, date by date. At each date there is exactly one generation of each age. Total consumption changes by \(-Y\tau + (N-Y)\cdot\frac{Y\tau}{N-Y} = 0\). No goods are created or destroyed.
  2. Prices rise over time. \(p_{s+1}/p_s = 1/(1+r_s) > 1\) when \(r_s<0\). So every price \(p_{t+a-1}\) with \(a>Y\) exceeds every price with \(a\le Y\).
  3. The transfer has positive value. Rewrite \(P^t(\tau,Y) = \frac{Y\tau}{p_t}\big[\overline{p}_{\text{late}} - \overline{p}_{\text{early}}\big]\), where \(\overline{p}_{\text{late}}\) is the average of the \(N-Y\) late prices and \(\overline{p}_{\text{early}}\) the average of the \(Y\) early ones. By step 2, \(P^t(\tau,Y)>0\).
  4. Marginal welfare. Differentiating utility at \(\tau=0\) and using the FOCs: $$\frac{d u^t}{d\tau}\Big|_{\tau=0} = \sum_a v^t_a\,\frac{dc^t_a}{d\tau} = \lambda^t \sum_a p_{t+a-1}\frac{dc^t_a}{d\tau} = \lambda^t p_t\, P^t(1,Y) > 0 .$$ This holds for every generation born at \(t\ge 1\).
  5. Generations already alive at date 1. A generation that is age \(a_0>1\) at date 1 experiences only the changes at ages \(a_0,\dots,N\). It skips some of the negative terms in \(P\), so its marginal value is even larger (if \(a_0>Y\), it only receives). So it gains too.
  6. Since every generation's marginal utility gain is strictly positive at \(\tau=0\), there is a \(\bar\tau>0\) such that all gain for \(\tau\in(0,\bar\tau)\). (With infinitely many generations one needs a single \(\bar\tau\) that works for all of them. That holds, for example, in a stationary equilibrium with constant \(r\), where every generation faces the same problem. The slides take this step as given.) ∎

Check: with \(N=2\), \(Y=1\), we get \(P = (p_{t+1}-p_t)/p_t = \frac{1}{1+r_t}-1\), positive iff \(r_t<0\). This is exactly the PAYG argument of Lesson 11.

Why this needs pure exchange III p.24

Step 1 checked feasibility only against a fixed endowment. With intertemporal production, a reallocation of consumption changes saving and therefore the capital path, as in Lesson 15. The new consumption plan must be matched by a feasible production and capital path, which is not automatic.

Interactive: value of the transfer. \(P^t(1,Y)\) as a function of a constant interest rate \(r\), for each \(Y=1,\dots,N-1\). With \(p_{t+a-1}/p_t = (1+r)^{-(a-1)}\), every curve is positive exactly when \(r<0\). Try: increase \(N\). The curves get steeper, because longer lives mean more periods over which a negative return compounds.

5. Check your understanding

1. Why does the equilibrium interest rate depend on the \(\alpha_n\) only through \(\bar\alpha\)?
  • Because each type's saving is linear in its α_n
  • Because each type faces a different interest rate
  • Because nobody trades with anyone in equilibrium
  • Because all types share the same lifetime wealth
\(s(\alpha,r) = \beta(1-\alpha) - (1-\beta)\alpha/(1+r)\) is affine in \(\alpha\), so average saving is \(s(\bar\alpha,r)\). With non-log preferences this exact aggregation generally fails. Types do trade, and their wealths differ.
2. In the worked example, why does type 2 (α = 0.55) lose from uniform PAYG?
  • It pays more tax than type 1 when it is young
  • It receives a smaller transfer when it is old
  • It borrows, and the policy raises interest rates
  • It lends, and the policy lowers interest rates
Taxes and transfers are identical across types. Type 2 is a borrower (\(s_2<0\)), and the policy raises \(r\) from \(-4/7\) to 0, which makes borrowing much more expensive.
3. In the \(N\)-period argument, what guarantees that the transfer is feasible?
  • Prices increase over time when interest rates are negative
  • Each date has one generation of each age, so flows net out
  • The first-order conditions hold for each generation alive
  • Each generation's budget constraint holds with equality
At any date, \(Y\) age groups each give \(\tau\) and \(N-Y\) age groups each receive \(Y\tau/(N-Y)\), so the net is zero. Rising prices are what make the transfer valuable, not what make it feasible.
4. With \(N=2\) and \(Y=1\), \(P^t(1,1)\) equals which expression?
  • \(r_t/(1+r_t)\), positive exactly when r is positive
  • \(1+r_t\), the gross return on saving from t to t+1
  • \(r_t\), the net interest rate between t and t+1
  • \(1/(1+r_t)-1\), positive exactly when r is negative
\(P = (-p_t + p_{t+1})/p_t = p_{t+1}/p_t - 1 = 1/(1+r_t) - 1\). This is the value at birth of paying 1 when young and receiving 1 when old, i.e. two-period PAYG.

6. Exercises

Exercise 16.1 Slides III p.20

Derive \(c_y(\alpha,r)\), \(c_o(\alpha,r)\) and the ratio formula from scratch, starting from the type-\(\alpha\) household problem with sequential budget constraints \(c_y + s = 1-\alpha\) and \(c_o = (1+r)s+\alpha\).

Show solution

Eliminate \(s\): \(c_y + c_o/(1+r) = W \equiv 1-\alpha+\alpha/(1+r)\). The Lagrangian FOCs are \((1-\beta)/c_y = \lambda\) and \(\beta/c_o = \lambda/(1+r)\), so \(c_y = (1-\beta)/\lambda\) and \(c_o/(1+r) = \beta/\lambda\). Substituting into the budget gives \(1/\lambda = W\). Hence \(c_y = (1-\beta)W\) and \(c_o = \beta(1+r)W = \beta[(1+r)(1-\alpha)+\alpha]\). Both are proportional to \(W\), so the ratio across types is \(W(\alpha,r)/W(\bar\alpha,r)\). Multiplying numerator and denominator by \(1+r\) gives \(\frac{(1+r)(1-\alpha)+\alpha}{(1+r)(1-\bar\alpha)+\bar\alpha} = \frac{1+(1-\alpha)r}{1+(1-\bar\alpha)r}\).

Exercise 16.2 Exam-style

Use the worked example (\(\beta=0.5\), \(\alpha_1=0.05\), \(\alpha_2=0.55\)).

  1. Compute \(\lambda_2\), type 2's weight in the rescaled allocation.
  2. Compute type 2's equilibrium consumption when young, \(c_y(0.55,\bar r)\).
  3. Check that this equals \(\lambda_2(1-\bar\alpha)\).
  4. In the rescaled allocation, what does type 2 consume when young? Is that more or less than in the CE? Why is it nevertheless better off?
Show solution

(a) \(\lambda_2 = \frac{1+0.45(-4/7)}{1+0.7(-4/7)} = \frac{1-1.8/7}{0.6} = \frac{5.2/7}{0.6} = 26/21\approx 1.238\).
(b) \(0.5(0.45 + 0.55\cdot 7/3) = 0.5(0.45+1.2833) = 0.8667\).
(c) \(\lambda_2\cdot 0.7 = 0.8667\). ✓
(d) \(\lambda_2(1-\beta) = 0.619 < 0.867\). Type 2 consumes less when young but much more when old: \(\lambda_2\beta = 0.619\) versus \(\lambda_2\bar\alpha = 0.371\). Its CE profile is tilted too far toward youth, because the negative interest rate made borrowing against old-age endowment cheap. The rescaled profile \((1-\beta,\beta)\) is the best shape, and log utility makes the gain independent of the scale \(\lambda_2\).

Exercise 16.3 Exam-style

In the worked example with \(\tau = \beta-\bar\alpha\), find the cutoff type \(\hat\alpha\) such that types with \(\alpha_n>\hat\alpha\) lose. Give a closed form in terms of \(\bar r\) and \(\beta\), and evaluate it.

Hint

After the policy, \(r=0\) and \(U_n = 0\) for every type. So the cutoff solves \(U_n(0) = 0\), i.e. \(\log W(\hat\alpha,\bar r) + \beta\log(1+\bar r) = 0\).

Show solution

\(W(\hat\alpha,\bar r) = (1+\bar r)^{-\beta}\), i.e. \(1 + \hat\alpha\big(\tfrac{1}{1+\bar r}-1\big) = (1+\bar r)^{-\beta}\), so $$\hat\alpha = \frac{(1+\bar r)^{-\beta} - 1}{(1+\bar r)^{-1} - 1} = \frac{(7/3)^{1/2}-1}{7/3 - 1} = \frac{0.5275}{1.3333}\approx 0.396 .$$ Since \(\hat\alpha>\bar\alpha=0.3\), some borrowers (those with \(\alpha_n\in(0.3,0.396)\)) still gain: the move of the consumption profile toward the optimal shape outweighs their higher borrowing cost.

Exercise 16.4 Exam-style (design a Pareto-improving policy)

Show that the rescaled allocation of §2 can be implemented as a competitive equilibrium with (i) a uniform PAYG tax \(\tau=\beta-\bar\alpha\) and (ii) lump-sum transfers \(T_n\) among the young of each generation, summing to zero. Find \(T_n\).

Show solution

With \(\tau=\beta-\bar\alpha\), the post-tax average old endowment is \(\beta\), so \(r=0\) (for any zero-sum within-generation transfers, since saving remains linear in endowments). At \(r=0\) a type-\(n\) young agent's wealth is \((1-\alpha_n-\tau+T_n) + (\alpha_n+\tau) = 1+T_n\). It consumes \((1-\beta)(1+T_n)\) and \(\beta(1+T_n)\). Matching the rescaled allocation requires \(1+T_n = \lambda_n\), i.e. $$T_n = \lambda_n - 1 = \frac{(\bar\alpha-\alpha_n)\,\bar r}{1+(1-\bar\alpha)\bar r}.$$ These sum to zero because \(\lambda_n\) averages to one. With \(\bar r<0\), high-\(\alpha_n\) types (the borrowers hurt by the rise in \(r\)) receive \(T_n>0\). The initial old receive \(\tau = \beta-\bar\alpha\), as in §2.

Exercise 16.5 Slides III pp.23–24

Let \(N=3\) and suppose the interest rate is constant at \(r=-0.1\).

  1. Compute \(P^t(1,1)\) (take 1 at age 1; give ½ at ages 2 and 3).
  2. Compute \(P^t(1,2)\) (take 1 at ages 1 and 2; give 2 at age 3).
  3. Show that a generation aged 2 at date 1 gains even more from the \(Y=2\) transfer than a newborn does.
Show solution

Let \(q=1/(1+r) = 1/0.9\). (a) \(-1 + \tfrac12(q+q^2) = -1 + \tfrac12(1.1111+1.2346)\approx 0.1728\). (b) \(-(1+q) + 2q^2 = -2.1111 + 2.4691 \approx 0.3580\). (c) The age-2 generation pays only at age 2 and receives 2 at age 3. Valued at its date-1 price, that is \(-1 + 2q \approx 1.222 > 0.358\). It skips the age-1 payment.

Exercise 16.6 Exam-style

Suppose instead that all equilibrium interest rates are positive. Consider the reverse transfer, from old ages to young ages. Show that it raises the value \(P^t\) for every generation born at \(t\ge 1\), but that it cannot be a Pareto improvement. Identify a generation that must lose.

Show solution

With \(r>0\) prices fall over time, so the reverse transfer has positive value for every generation born at \(t\ge1\): it receives early, when goods are expensive, and pays late, when they are cheap. But a generation aged \(a_0>Y\) at date 1 only pays; it receives nothing in its remaining life. It strictly loses. This is consistent with the First Welfare Theorem: with \(r>0\), the value of the aggregate endowment is finite (Lesson 12), so the equilibrium is Pareto optimal.

Exercise 16.7 Slides III p.24

Explain in a few sentences why the \(N\)-period argument "does not automatically go through" with intertemporal production. Use the Cobb–Douglas model of Lesson 15 as an example.

Show solution

With production, the set of feasible consumption paths depends on the capital path. Moving consumption from the young to the old changes saving, hence \(K_{t+1}\), output and factor prices. So "total consumption unchanged each period" no longer guarantees feasibility, because output itself changes. And welfare effects include price effects. In Lesson 15, PAYG lowered \(K\), and whether steady-state generations gained depended on \(r^*\), not merely on the sign of a valuation like \(P^t\). The negative-interest-rate argument must be redone with a feasible production plan.

Key takeaways

  • With log utility, type-\(\alpha\) consumption is the average type's bundle scaled by \(\frac{1+(1-\alpha)r}{1+(1-\bar\alpha)r}\), and saving is linear in \(\alpha\). So \(\bar r = \frac{\bar\alpha-\beta}{\beta(1-\bar\alpha)}\) depends only on \(\bar\alpha\).
  • There is trade within generations: low-\(\alpha\) types lend to high-\(\alpha\) types.
  • If \(\bar\alpha<\beta\), the wealth-rescaled best symmetric allocation, plus \(\beta-\bar\alpha\) to the initial old, Pareto-dominates the CE.
  • Uniform PAYG raises \(r\) and hurts borrowers: correcting aggregate inefficiency does not settle the distribution of gains.
  • With \(N\)-period lives and \(r<0\), any small young-to-old transfer has positive value \(P^t\) for every generation and is a Pareto improvement in pure exchange.

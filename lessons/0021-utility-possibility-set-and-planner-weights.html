The Planner Problem and Pareto Weights

1. The big picture

The two welfare theorems connect competitive equilibria with Pareto optima. This lesson adds a third object: the solution to a planner's problem that maximizes a weighted sum of utilities, $$W(\lambda):\qquad \max_{\{x^i,y^j\}}\ \sum_{i\in I}\lambda_i\,u^i(x^i)\quad\text{subject to feasibility.}$$ The main theorem says that, under convexity assumptions, the Pareto optima are exactly the solutions of \(W(\lambda)\) as \(\lambda\) ranges over non-negative weight vectors N3 s.5. That is what licenses the "representative agent" of macroeconomics: a single maximization problem whose objective is \(\sum_i\lambda_iu^i\) N3 s.1. Lesson 23 will show that the CE weights are \(\lambda_i=1/\mu_i\), the reciprocal of each household's marginal utility of income.

Intuition: pick a direction, then climb

Pareto optimality is a statement about a set: no feasible point is better for everyone. A planner with weights \(\lambda\) instead maximizes a single number, "move as far as possible in direction \(\lambda\)". If the set of attainable utility vectors is convex, every point on its outer edge is the farthest point in some direction. So choosing \(\lambda\) is the same as choosing where on the Pareto frontier to be, i.e. choosing a distribution of welfare.

2. The utility possibility set

Definition: utility possibility set N3 s.3

$$U=\Big\{u\in\mathbb R^I:\ u_i\le u^i(x^i)\ \text{for all } i\in I,\ \text{for some feasible allocation }\{x^i,y^j\}\Big\}.$$

Feasible means \(x^i\in X^i\), \(y^j\in Y^j\) and \(\sum_ix^i\le\sum_jy^j+\sum_ie^i\) (the slides' exchange economy, eq. (1), allows disposal: N3 s.14).

Three features of this definition do real work later.

  • It lives in utility space, not commodity space. Each point is a list of \(I\) utility numbers. In Lesson 6 we separated sets of bundles in \(\mathbb R^m\). Here we separate in \(\mathbb R^I\), and the normal vector will be a vector of weights on people, not prices of goods.
  • The "\(\le\)" makes \(U\) downward comprehensive N3 s.8: if \(u\in U\) and \(u'\le u\) componentwise, then \(u'\in U\) (use the same allocation). So \(U\) extends forever down and to the left. This is what makes the weights non-negative.
  • The Pareto frontier is part of the boundary of \(U\). If \(\bar x\) is PO, then \(\bar u=(u^i(\bar x^i))_i\) is not in the interior of \(U\) (proved in §4). The converse fails: points on vertical or horizontal stretches of the boundary are not PO (§6).

3. When is \(U\) convex?

The theorem's key step separates \(U\) with a hyperplane, which needs \(U\) to be convex. We get there in two steps: convexity of the set of feasible allocations, then convexity of \(U\).

Step A: feasible allocations form a convex set N3 s.3, Question

If the aggregate production set \(Y=\sum_jY^j\) and every \(X^i\) are convex (Assumptions FF and the first half of HH from Lesson 6), then the set \(\mathcal F\) of feasible allocations is convex.

Proof
  1. Write feasibility in aggregate form. An allocation is a list \((x^1,\dots,x^I,y)\) with \(x^i\in X^i\), \(y\in Y\) and \(\sum_ix^i\le y+\bar e\), where \(\bar e=\sum_ie^i\). (Only the aggregate \(y=\sum_jy^j\) matters for feasibility, which is why FF is stated for \(Y\).)
  2. Take two feasible allocations \((x^i,y)\) and \((\hat x^i,\hat y)\), and \(t\in[0,1]\). Let \(x^i_t=tx^i+(1-t)\hat x^i\) and \(y_t=ty+(1-t)\hat y\).
  3. Each piece stays in its set. \(x^i_t\in X^i\) because \(X^i\) is convex; \(y_t\in Y\) because \(Y\) is convex.
  4. The resource constraint is linear, so it survives averaging. Multiply \(\sum_ix^i\le y+\bar e\) by \(t\) and \(\sum_i\hat x^i\le\hat y+\bar e\) by \(1-t\), and add: \(\sum_ix^i_t\le y_t+\bar e\). So \((x^i_t,y_t)\in\mathcal F\).
∎

Convexity of \(\mathcal F\) is not enough for convexity of \(U\): the map from allocations to utilities can bend a convex set into a non-convex one. We need a property of the functions \(u^i\) themselves.

Assumption CC N3 s.4

Every \(u^i\) is concave: \(u^i(tx+(1-t)x')\ge tu^i(x)+(1-t)u^i(x')\) for all \(x,x'\in X^i\), \(t\in[0,1]\).

Concavity is cardinal, not ordinal N3 s.4, Question

An ordinal property survives every strictly increasing transformation \(f\), since \(f\circ u\) represents the same preferences and generates the same demands. Concavity does not survive.

  • Counterexample. \(u(x)=\log x\) on \(x>0\) is concave. Its transformation \(v=e^{2u}=x^2\) represents the same preferences (more is better) but is strictly convex.
  • In the other direction, \(u(x_1,x_2)=x_1x_2\) is not concave (along the diagonal it equals \(t^2\)), but \(\sqrt{x_1x_2}\), which represents the same preferences, is concave.
  • The ordinal cousin is quasi-concavity: convex upper contour sets \(\{x:u(x)\ge c\}\). A strictly increasing \(f\) maps these sets into each other, \(\{f(u)\ge f(c)\}=\{u\ge c\}\), so quasi-concavity is preserved. Assumption HH from Lesson 6 is quasi-concavity, an ordinal assumption; CC is a strictly stronger, cardinal one.

So CC is an assumption about the utility numbers we feed the planner, not about behaviour. This matters in §7.

Step B: under HH, FF and CC, \(U\) is convex N3 s.4, Question
Proof
  1. Pick two points of \(U\) and their allocations. Let \(u,\hat u\in U\). By definition there are feasible allocations \(x\) and \(\hat x\) with \(u_i\le u^i(x^i)\) and \(\hat u_i\le u^i(\hat x^i)\) for every \(i\).
  2. Average the allocations. For \(t\in[0,1]\), \(x_t=tx+(1-t)\hat x\) is feasible by Step A (this uses convex \(X^i\) and \(Y\)).
  3. Use concavity, agent by agent. \(u^i(x^i_t)\ge t\,u^i(x^i)+(1-t)\,u^i(\hat x^i)\ge t\,u_i+(1-t)\,\hat u_i\).
  4. Use the "\(\le\)" in the definition of \(U\). Step 3 says the vector \(tu+(1-t)\hat u\) is weakly below the utilities delivered by the feasible allocation \(x_t\). Hence \(tu+(1-t)\hat u\in U\).
∎

Step 3 is the only place CC enters. With merely quasi-concave \(u^i\), we only know \(u^i(x^i_t)\ge\min\{u^i(x^i),u^i(\hat x^i)\}\), which bounds \(x_t\)'s utility below by the worse endpoint, not by the average. That is too weak to put \(tu+(1-t)\hat u\) in \(U\).

4. The theorem: Pareto optima are planner solutions

Theorem N3 s.5

Assume the \(u^i\) are strictly increasing, that HH, CC and FF hold, and that \(U\) has a nonempty interior.

  1. (Sufficiency.) If \(\lambda\in\mathbb R^I_{++}\) (all weights strictly positive) and \(\{\bar x^i,\bar y^j\}\) solves \(W(\lambda)\), then \(\{\bar x^i,\bar y^j\}\) is Pareto optimal.
  2. (Necessity.) If \(\{\bar x^i,\bar y^j\}\) is Pareto optimal, there is a nonzero \(\lambda\in\mathbb R^I_+\) for which it solves \(W(\lambda)\).

Notice the asymmetry: strictly positive weights in part 1, merely non-negative weights in part 2. Both halves are sharp, as §6 shows.

Proof of 1 (sufficiency) N3 s.6
  1. Suppose not. Let \(\lambda\gg0\) and let \(\bar x\) solve \(W(\lambda)\), but suppose some feasible \(\hat x\) Pareto-dominates it: \(u^i(\hat x^i)\ge u^i(\bar x^i)\) for all \(i\), with strict inequality for some \(k\).
  2. Weight and add. Multiply each inequality by \(\lambda_i\ge0\) and sum: \(\sum_i\lambda_iu^i(\hat x^i)\ge\sum_i\lambda_iu^i(\bar x^i)\).
  3. Strict positivity makes it strict. Agent \(k\)'s term is strictly larger and \(\lambda_k>0\), so \(\lambda_ku^k(\hat x^k)>\lambda_ku^k(\bar x^k)\) and the sum inequality is strict.
  4. Contradiction. \(\hat x\) is feasible and gives a strictly higher value of the planner's objective than \(\bar x\), which was supposed to be a maximizer.
∎

What this used: only \(\lambda\gg0\). No convexity, no concavity, no monotonicity. If \(\lambda_k=0\), step 3 fails: the agent who gains gets no weight, so \(\hat x\) only ties with \(\bar x\).

Proof of 2 (necessity) N3 s.7–8
  1. Map the optimum into utility space. Let \(\bar u=(u^1(\bar x^1),\dots,u^I(\bar x^I))\). It is in \(U\), using \(\bar x\) itself.
  2. \(\bar u\) is on the boundary of \(U\). If \(\bar u\) were interior, then \(\bar u+\varepsilon\mathbf 1\in U\) for some \(\varepsilon>0\). Some feasible \(x\) would then give \(u^i(x^i)\ge\bar u_i+\varepsilon>\bar u_i\) for every \(i\), contradicting Pareto optimality of \(\bar x\).
  3. Support \(U\) at \(\bar u\). \(U\) is convex (Step B, which uses HH, FF, CC). By the supporting hyperplane theorem, a convex set has a supporting hyperplane at every boundary point: there is \(\lambda^*\in\mathbb R^I\), \(\lambda^*\ne0\), with $$\lambda^*\cdot\bar u\ \ge\ \lambda^*\cdot u\qquad\text{for every }u\in U.$$
  4. Translate back to allocations. For any feasible \(x\), the vector \((u^i(x^i))_i\) lies in \(U\). Step 3 then says \(\sum_i\lambda^*_iu^i(x^i)\le\sum_i\lambda^*_iu^i(\bar x^i)\): \(\bar x\) solves \(W(\lambda^*)\).
  5. The weights are non-negative N3 s.8. Suppose \(\lambda^*_i\lt 0\) for some \(i\). By downward comprehensiveness, \(\bar u-\varepsilon e_i\in U\) for \(\varepsilon>0\) (\(e_i\) is the \(i\)th unit vector: lower agent \(i\)'s utility and nobody else's). Then $$\lambda^*\cdot(\bar u-\varepsilon e_i)=\lambda^*\cdot\bar u-\varepsilon\lambda^*_i>\lambda^*\cdot\bar u,$$ contradicting step 3. So \(\lambda^*\ge0\), and \(\lambda^*\ne0\) from step 3.
∎

Intuition: the same move as the Second Welfare Theorem, one level up

In Lesson 6 we separated the "better than" set from the production set in commodity space; the normal was a price vector. Here we support the utility possibility set in utility space; the normal is a vector of Pareto weights. In both cases convexity is what guarantees that a linear functional (prices, or weights) can "see" the optimum. In both cases the sign of the normal comes from free disposal or comprehensiveness: you can always throw goods (or utility) away.

5. See it: frontiers, weights, and unsupported optima

Two households share an aggregate endowment \(\bar e=(1,1)\) of two goods and have identical preferences \(u^i(x_1,x_2)=(x_1x_2)^k\), \(k>0\). The preferences are Cobb–Douglas for every \(k\), so they are strictly quasi-concave and every Pareto optimum lies on the diagonal of the Edgeworth box: agent 1 gets \(s\bar e\) and agent 2 gets \((1-s)\bar e\) (Exercise 21.5 proves this). Utilities are then \(u_1=s^{2k}\) and \(u_2=(1-s)^{2k}\), so the Pareto frontier is $$u_1^{1/(2k)}+u_2^{1/(2k)}=1 .$$ \(u^i\) is concave exactly when \(2k\le1\), and that is also exactly when \(U\) is convex.

6. Zero weights: necessary sometimes, dangerous always

The theorem's two halves use different weight sets, and the slides warn that this is not cosmetic N3 s.9. Two examples make both points.

(a) A maximizer of \(W\) that is not Pareto optimal

One good, aggregate endowment \(\bar e\), two households with \(u^i(x)=x\). Household 1 can consume at most \(a\lt\bar e\): \(X^1=[0,a]\), \(X^2=\mathbb R_+\). Feasibility is \(x^1+x^2\le\bar e\). All assumptions of the theorem hold (the \(X^i\) are convex intervals, the \(u^i\) linear, hence concave and strictly increasing).

  • \(U\) in the positive quadrant is \(\{u_1\le a,\ u_1+u_2\le\bar e\}\): a slope \(-1\) edge from \((0,\bar e)\) to \((a,\bar e-a)\), then a vertical edge down from \((a,\bar e-a)\).
  • Take \(\lambda=(1,0)\). \(W\) maximizes \(x^1\) alone, so every allocation with \(x^1=a\) and \(x^2\in[0,\bar e-a]\) solves it.
  • Only \(x^2=\bar e-a\) is Pareto optimal. Every other maximizer throws away goods that household 2 would like, which a Pareto improvement can give to 2 at no cost to 1.
The vertical edge of \(U\) (orange) is the set of solutions of \(W\) with \(\lambda=(1,0)\), drawn for \(\bar e=1\), \(a=0.6\). Only its top end is Pareto optimal. With a zero weight, the planner simply does not care whether household 2's goods are thrown away.

A rescue. If the solution of \(W(\lambda)\), \(\lambda\ge0\), is unique, it is Pareto optimal. Proof: a Pareto-dominating \(\hat x\) would satisfy \(\sum_i\lambda_iu^i(\hat x^i)\ge\sum_i\lambda_iu^i(\bar x^i)\) (weights are non-negative), so \(\hat x\) would be another maximizer. And \(\hat x\ne\bar x\), since someone is strictly better off under \(\hat x\). That contradicts uniqueness.

(b) A Pareto optimum that needs a zero weight

One good, \(\bar e=1\), \(u^1(x)=\sqrt x\), \(u^2(x)=\sqrt x\). The frontier is the quarter circle \(u_1^2+u_2^2=1\). The allocation "household 1 gets everything", \(\bar u=(1,0)\), is Pareto optimal. But the circle is vertical there, so its only supporting normal is \(\lambda\propto(1,0)\). With \(\lambda_2>0\) the planner always gives household 2 something, because \(u^{2\prime}(0)=\infty\). So in the necessity half, \(\mathbb R^I_+\) cannot be replaced by \(\mathbb R^I_{++}\).

The qualification, in one sentence N3 s.9

Every Pareto optimum is a planner solution, but some need zero weights; and once zero weights are allowed, a planner solution need not be Pareto optimal. For the smooth interior allocations of Lessons 22–25 neither problem arises, so from now on we work with \(\lambda\gg0\).

7. The slide 10 questions, answered

N3 s.10 asks three drawing questions. The figure in §5 lets you do all of them.

(i) Convex \(U\): how to find the \(\lambda\) that picks \(\bar u\)
  1. Draw the supporting line. Pick \(\bar u\) on the frontier and draw a line through \(\bar u\) with all of \(U\) on one side. Convexity guarantees one exists; at a smooth point it is the tangent line.
  2. Take its outward normal. That normal is \(\lambda\). Because the frontier slopes down (strictly increasing \(u^i\), so \(U\) is comprehensive), the normal points north-east: \(\lambda\ge0\).
  3. Read off the weights from the slope. The iso-welfare lines \(\lambda_1u_1+\lambda_2u_2=c\) have slope \(-\lambda_1/\lambda_2\). At a smooth interior solution, the frontier's slope equals \(-\lambda_1/\lambda_2\). Steep frontier at \(\bar u\) means a large \(\lambda_1/\lambda_2\): to justify giving household 1 a lot, the planner must care a lot about household 1.
(ii) Non-convex \(U\): a Pareto optimum that solves \(W\) for no \(\lambda\)

Draw a frontier that bows inward (towards the origin), like the §5 figure with \(k>\tfrac12\), and pick an interior point \(\bar u\). Any line through \(\bar u\) with non-negative normal either crosses into \(U\) on one side or is the tangent. In the tangent case, the frontier lies above the line on both sides, so \(\bar u\) is a local minimum of \(\lambda\cdot u\) along the frontier. For every \(\lambda\ge0\), some other point of \(U\), a corner here, gives a higher \(\lambda\cdot u\). So \(\bar u\) is Pareto optimal but is not the solution to any planner problem.

(iii) Can this happen with strictly quasi-concave (but not concave) \(u^i\)?

Yes. The §5 economy is the example: \(u^i=(x_1x_2)^k\) is strictly quasi-concave for every \(k>0\) (its upper contour sets are those of Cobb–Douglas), but for \(k>\tfrac12\) it is not concave and the frontier \(u_1^{1/(2k)}+u_2^{1/(2k)}=1\) bows inward. An even simpler example: one good, \(u^i(x)=x^2\). With one good, any strictly increasing function is strictly quasi-concave, and the frontier \(\sqrt{u_1}+\sqrt{u_2}=\bar e\) bows inward.

The deeper point. The set of Pareto-optimal allocations is ordinal: it depends only on preferences. In the §5 economy it is the diagonal of the box for every \(k\). Whether every Pareto optimum is reachable as a solution of \(W\) depends on which utility numbers we use. Replace \(u^i=(x_1x_2)^k\) by the equivalent \(v^i=(u^i)^{1/(2k)}=\sqrt{x_1x_2}\), which is concave. The new frontier is the straight line \(v_1+v_2=1\), and every Pareto optimum solves \(W\) (with equal weights; the planner is indifferent along the line). So when preferences admit a concave representation, the planner approach can trace out every Pareto optimum: choose that representation. This is why the theorem assumes CC, a cardinal assumption, even though everything it describes is ordinal.

8. Where this goes next: the representative agent

Fix \(\lambda\gg0\) and suppose there is no production. Then \(W(\lambda)\) is a problem of splitting a given aggregate bundle \(x\) among households. Its value, $$u(x;\lambda)=\max_{\{x^i\}}\ \sum_i\lambda_iu^i(x^i)\quad\text{s.t.}\quad\sum_ix^i=x,$$ is the utility function of a single representative agent N3 s.11. By this lesson's theorem and the welfare theorems, every CE corresponds to some \(\lambda\). Lesson 22 studies \(u(\cdot;\lambda)\) and the planner's first-order conditions. Lesson 23 finds the CE's \(\lambda\). Lessons 24–25 ask when the representative agent's prices do not depend on \(\lambda\) at all (aggregation).

9. Check your understanding

1. Which feature of the setup makes the supporting weights \(\lambda^*\) non-negative?
  • U contains every vector below any of its points
  • Every utility function is concave in its own consumption
  • Every utility function is strictly increasing in each good
  • The utility possibility set U has a nonempty interior
The "\(\le\)" in the definition of \(U\) makes it downward comprehensive. If \(\lambda^*_i\lt0\), lowering agent \(i\)'s utility would stay inside \(U\) and raise \(\lambda^*\cdot u\), contradicting the support inequality. Concavity gives convexity of \(U\) (existence of some \(\lambda^*\)), not its sign.
2. Which direction of the theorem needs convexity of \(U\)?
  • Sufficiency: planner solutions with strictly positive weights are optimal
  • Both directions, because both of them use a hyperplane
  • Necessity: every Pareto optimum solves some weighted planner problem
  • Neither direction, because the weights carry all the information
Sufficiency is a three-line contradiction that only uses \(\lambda\gg0\). Necessity needs a supporting hyperplane at \(\bar u\), which exists at every boundary point only if \(U\) is convex.
3. Replace every \(u^i\) by \(e^{u^i}\). Which statement is right?
  • The Pareto set changes, and so does the convexity of U
  • The Pareto set stays, but the convexity of U may change
  • The Pareto set changes, but the convexity of U is unchanged
  • The Pareto set stays, and the convexity of U is unchanged
A strictly increasing transformation preserves preferences, hence the set of PO allocations. But it reshapes \(U\): concavity is cardinal, and a convex \(U\) can become non-convex (and vice versa).
4. With \(\lambda=(1,0,\dots,0)\), when is a solution of \(W(\lambda)\) guaranteed to be Pareto optimal?
  • Always, since the weight vector is non-negative and nonzero
  • Never, since the other households receive zero planner weight
  • Whenever every utility function is both concave and strictly increasing
  • Whenever it is the unique solution of that planner problem
A Pareto-dominating allocation would tie in the weighted sum, so it would be a second maximizer. Uniqueness rules that out. Concavity and monotonicity are not enough: in §6(a) all assumptions hold, yet most maximizers are not PO.
5. At a smooth interior solution of \(W(\lambda)\) with \(I=2\), the slope \(du_2/du_1\) of the frontier equals:
  • \(-\lambda_1/\lambda_2\), the slope of the planner's iso-welfare lines
  • \(-\lambda_2/\lambda_1\), the reciprocal slope of the iso-welfare lines
  • \(-1\), whatever weights the planner happens to choose
  • \(-p_1/p_2\), the ratio of the two goods' prices
The planner moves along \(U\)'s edge until the frontier is tangent to \(\lambda_1u_1+\lambda_2u_2=c\), whose slope is \(-\lambda_1/\lambda_2\). Price ratios are slopes in commodity space, not utility space.

10. Exercises

No past exam has asked directly about \(U\) or this theorem; the exam questions on Class Note 3 start from the planner's first-order conditions (Lessons 22–25). These exercises cover the in-slide questions and use Alvarez's formats: true/false with short justifications, and proofs broken into small graded steps. Knowing exactly which assumption does what is how Midterm 1 true/false items about the welfare theorems are won.

Exercise 21.1 True or false? Justify. Exam-inspired

Answer True or False and justify in at most four lines. Unless stated otherwise, HH, FF and CC hold and the \(u^i\) are strictly increasing.

  1. Every Pareto-optimal allocation solves \(W(\lambda)\) for some \(\lambda\in\mathbb R^I_{++}\). exam-inspired (N3 s.5)
    Answer

    False. The theorem only delivers \(\lambda\in\mathbb R^I_+\setminus\{0\}\). Counterexample (§6b): one good, \(u^i=\sqrt x\). The corner allocation giving everything to household 1 is PO, but the frontier \(u_1^2+u_2^2=1\) is vertical there, so the only supporting weights are \(\lambda\propto(1,0)\).

  2. If \(\lambda\in\mathbb R^I_{++}\) and \(\bar x\) solves \(W(\lambda)\), then \(\bar x\) is Pareto optimal, even if the \(u^i\) are not concave and the \(X^i\) are not convex. exam-inspired (N3 s.6)
    Answer

    True. The sufficiency proof uses only \(\lambda\gg0\): a Pareto-dominating feasible allocation would raise \(\sum_i\lambda_iu^i\) strictly, since the agent who gains has positive weight. No convexity is involved.

  3. If \(\lambda\in\mathbb R^I_+\), \(\lambda\ne0\), and \(\bar x\) solves \(W(\lambda)\), then \(\bar x\) is Pareto optimal. exam-inspired (N3 s.9)
    Answer

    False. With \(\lambda_k=0\), a Pareto improvement that only helps agent \(k\) leaves \(W\) unchanged, so a non-PO allocation can tie for the maximum. Example (§6a): \(X^1=[0,a]\), \(u^i=x\), disposal allowed, \(\lambda=(1,0)\): every allocation with \(x^1=a\) maximizes \(W\), but only \(x^2=\bar e-a\) is PO. It becomes true if the maximizer is unique.

  4. In the theorem, concavity of the \(u^i\) (CC) can be replaced by strict quasi-concavity. exam-inspired (N3 s.10)
    Answer

    False. Two households, \(\bar e=(1,1)\), \(u^i=(x_1x_2)^k\) with \(k>\tfrac12\): strictly quasi-concave, not concave. The frontier \(u_1^{1/(2k)}+u_2^{1/(2k)}=1\) bows inward, so \(U\) is not convex and interior PO points solve \(W(\lambda)\) for no \(\lambda\): \(W\) always picks a corner.

  5. Concavity of \(u^i\) is an ordinal property of preferences. N3 s.4, Question
    Answer

    False. \(\log x\) is concave, but the equivalent representation \(e^{2\log x}=x^2\) is convex. Concavity is cardinal; its ordinal counterpart is quasi-concavity (convex upper contour sets are preserved by increasing transformations).

  6. The set of Pareto-optimal allocations depends on the utility representation chosen for each household. exam-inspired
    Answer

    False. "Some agent strictly better off and nobody worse off" only compares bundles, so it is invariant to strictly increasing transformations. What does depend on the representation is the shape of \(U\), and hence whether every PO allocation can be obtained from \(W\) (§7(iii)).

  7. If \(\bar x\) is Pareto optimal, then \(\bar u=(u^i(\bar x^i))_i\) lies in the interior of \(U\). exam-inspired (N3 s.7)
    Answer

    False. It lies on the boundary. If \(\bar u\) were interior, \(\bar u+\varepsilon\mathbf 1\in U\) for small \(\varepsilon>0\), so a feasible allocation would make everyone strictly better off.

  8. The Pareto weights that support a given Pareto optimum are unique up to a positive scalar. exam-inspired
    Answer

    False. At a kink of the frontier, many supporting lines exist. In §6(a) the point \((a,\bar e-a)\) is supported by every \(\lambda=(\lambda_1,\lambda_2)\) with \(\lambda_1\ge\lambda_2\ge0\). Weights are unique up to scale where the frontier is smooth.

  9. If each \(Y^j\) and each \(X^i\) is convex, the set of feasible allocations is convex. N3 s.3, Question
    Answer

    True. The sum \(Y=\sum_jY^j\) of convex sets is convex. Convex combinations of feasible allocations keep each \(x^i\in X^i\) and \(y\in Y\), and the resource constraint is linear (Step A).

Exercise 21.2 N3 s.3–4, Questions Proof (convexity of \(U\))
  1. Show that if \(Y\) and all \(X^i\) are convex, the set of feasible allocations is convex. (10 pts)
  2. Is concavity of \(u^i\) cardinal or ordinal? Give a counterexample to the wrong answer in one line. (5 pts)
  3. Show that HH, FF and CC imply \(U\) is convex. (15 pts)
  4. Point to the step in (c) that uses the "\(\le\)" in the definition of \(U\). Would \(U'=\{(u^i(x^i))_i: x\text{ feasible}\}\) (with "\(=\)") be convex under the same assumptions? (10 pts)
Hint for (d)

Try one good, two households, \(\bar e=1\), \(u^i(x)=\sqrt x\), and no disposal (\(x^1+x^2=1\)). What shape is \(U'\)?

Show solution

(a) Step A in §3: averaging keeps each piece in its convex set, and adding \(t\times\) and \((1-t)\times\) the two resource constraints gives the resource constraint for the average.
(b) Cardinal. \(\log x\) is concave, \(x^2=e^{2\log x}\) represents the same preferences and is convex.
(c) Step B in §3: \(u^i(x^i_t)\ge tu^i(x^i)+(1-t)u^i(\hat x^i)\ge tu_i+(1-t)\hat u_i\), and \(x_t\) is feasible.
(d) Step 4: the averaged vector is only weakly below the utilities of \(x_t\), and "\(\le\)" is what puts it in \(U\). \(U'\) need not be convex. In the hint's example, \(U'=\{(\sqrt t,\sqrt{1-t}):t\in[0,1]\}\) is a quarter circle (a curve), and the midpoint of \((1,0)\) and \((0,1)\), namely \((\tfrac12,\tfrac12)\), is not on it.

Exercise 21.3 N3 s.5–8 Proof (the theorem, assumption by assumption)
  1. Prove: if \(\lambda\gg0\) and \(\bar x\) solves \(W(\lambda)\), then \(\bar x\) is PO. Which step fails if \(\lambda_k=0\) for some \(k\)? (10 pts)
  2. Let \(\bar x\) be PO. Show that \(\bar u\) is not in the interior of \(U\). (5 pts)
  3. State the supporting hyperplane theorem you need, and use it to show that \(\bar x\) solves \(W(\lambda^*)\) for some \(\lambda^*\ne0\). Which assumptions does this step use, and how? (15 pts)
  4. Show that \(\lambda^*\ge0\). (10 pts)
  5. The theorem assumes \(U\) has a nonempty interior. Show that this holds automatically when at least one feasible allocation exists. (5 pts)
Show solution

(a) §4, sufficiency. With \(\lambda_k=0\), step 3 fails: a dominating \(\hat x\) that is strictly better only for \(k\) gives the same weighted sum.
(b) §4, necessity step 2.
(c) If \(C\subset\mathbb R^I\) is convex and \(\bar u\) is not in its interior, there is \(\lambda^*\ne0\) with \(\lambda^*\cdot\bar u\ge\lambda^*\cdot u\) for all \(u\in C\). Apply it to \(C=U\), which is convex by HH (convex \(X^i\)), FF (convex \(Y\)) and CC (concave \(u^i\)). For any feasible \(x\), \((u^i(x^i))_i\in U\), so \(\sum\lambda^*_iu^i(x^i)\le\sum\lambda^*_iu^i(\bar x^i)\).
(d) §4, necessity step 5: if \(\lambda^*_i\lt0\), then \(\bar u-\varepsilon e_i\in U\) and \(\lambda^*\cdot(\bar u-\varepsilon e_i)>\lambda^*\cdot\bar u\), a contradiction.
(e) If \(x\) is feasible, \(u(x)\in U\), so the whole orthant \(u(x)-\mathbb R^I_+\subseteq U\). It contains the open set \(\{u: u_i\lt u^i(x^i)\ \forall i\}\).

Exercise 21.4 Exam-inspired (power utility: when does the planner reach every optimum?)

One good with aggregate endowment \(\bar e>0\), two households, \(u^i(x)=x^a\) with \(a>0\), \(x^i\ge0\), \(x^1+x^2=\bar e\).

  1. Show that every feasible allocation is Pareto optimal, and that the frontier is \(u_1^{1/a}+u_2^{1/a}=\bar e\). (5 pts)
  2. For which \(a\) is \(U\) convex? Relate your answer to CC. (10 pts)
  3. Let \(a\lt1\) and \(\lambda\gg0\). Solve \(W(\lambda)\) and show that household 1's share is \(\dfrac{x^1}{\bar e}=\dfrac{\lambda_1^{1/(1-a)}}{\lambda_1^{1/(1-a)}+\lambda_2^{1/(1-a)}}\). Is \(x^1\) increasing in \(\lambda_1\)? (10 pts)
  4. Still with \(a\lt1\): given any target share \(s\in(0,1)\), find the weights \(\lambda_1/\lambda_2\) that implement it. Conclude that every interior Pareto optimum is supported by strictly positive weights. (10 pts)
  5. Let \(a>1\). Show that for every \(\lambda\ge0\), \(\lambda\ne0\), \(W(\lambda)\) is solved only at corners. Which Pareto optima are planner solutions? (10 pts)
  6. Is the household's behaviour different for \(a\lt1\) and \(a>1\)? What does that tell you about CC? (5 pts)
Hint

For (e), the objective \(\lambda_1x^a+\lambda_2(\bar e-x)^a\) is strictly convex in \(x\) when \(a>1\). Where does a strictly convex function on an interval attain its maximum?

Show solution

(a) One good and strictly increasing utilities: any reallocation that helps one household hurts the other, and nothing is wasted under \(x^1+x^2=\bar e\). With \(u_i=(x^i)^a\), \(x^i=u_i^{1/a}\), and the resource constraint gives the frontier.
(b) The frontier is \(u_2=(\bar e-u_1^{1/a})^a\). \(U\) is convex iff this is a concave function of \(u_1\). That holds iff \(a\le1\), which is exactly when \(x^a\) is concave (CC). For \(a>1\) it bows inward. (For \(a=1\) it is the line \(u_1+u_2=\bar e\).)
(c) FOC: \(\lambda_1a(x^1)^{a-1}=\lambda_2a(x^2)^{a-1}\), so \((x^1/x^2)^{1-a}=\lambda_1/\lambda_2\), i.e. \(x^1/x^2=(\lambda_1/\lambda_2)^{1/(1-a)}\). The objective is strictly concave, so the FOC characterizes the maximum; combine with \(x^1+x^2=\bar e\). Yes, since \(1/(1-a)>0\): more weight, more consumption.
(d) Invert: \(\lambda_1/\lambda_2=\big(s/(1-s)\big)^{1-a}\in(0,\infty)\). Every interior share is reached by some \(\lambda\gg0\). (The corners \(s\in\{0,1\}\) need \(\lambda_2=0\) or \(\lambda_1=0\), because \(u^{i\prime}(0)=\infty\).)
(e) A strictly convex function on \([0,\bar e]\) attains its maximum only at endpoints. So the planner gives everything to household 1 if \(\lambda_1\bar e^a>\lambda_2\bar e^a\), i.e. \(\lambda_1>\lambda_2\), to household 2 if \(\lambda_1\lt\lambda_2\), and either corner if they are equal. Only the two corner allocations are planner solutions, though every allocation is PO.
(f) No: with one good, every \(a>0\) represents "more is better". Preferences, and hence the PO set, are identical for all \(a\). CC is a restriction on the utility numbers, and with \(a>1\) the planner approach fails purely because of the representation. Use \(v^i=(u^i)^{1/a}=x\) instead and every PO point is a planner solution.

Exercise 21.5 N3 s.10, Questions Exam-inspired (strictly quasi-concave is not enough)

Two households, two goods, \(\bar e=(1,1)\), identical utilities \(u^i(x_1,x_2)=(x_1x_2)^k\), \(k>0\). No disposal.

  1. Show that \(u^i\) is strictly quasi-concave for every \(k>0\), and concave if and only if \(k\le\tfrac12\). (10 pts)
  2. Show that at an interior Pareto optimum the two households' MRSs are equal, and deduce that the contract curve is the diagonal \(x^1=s\bar e\), \(s\in[0,1]\). (10 pts)
  3. Derive the Pareto frontier \(u_1^{1/(2k)}+u_2^{1/(2k)}=1\). For which \(k\) does it bow inward? (5 pts)
  4. Let \(k>\tfrac12\). Show that no interior Pareto optimum solves \(W(\lambda)\) for any \(\lambda\ge0\), \(\lambda\ne0\). (10 pts)
  5. Find a utility representation of the same preferences under which every Pareto optimum solves \(W(\lambda)\) for some \(\lambda\). What are the weights? (5 pts)
Hint

(a) \(k\log x_1+k\log x_2\) is an increasing transformation of \(u^i\). A Cobb–Douglas function \(x_1^{b}x_2^{c}\) is concave iff \(b+c\le1\). (d) Along the frontier the weighted sum is \(\lambda_1s^{2k}+\lambda_2(1-s)^{2k}\); look at its second derivative in \(s\).

Show solution

(a) \(\log u^i=k(\log x_1+\log x_2)\) is strictly concave, so its upper contour sets are strictly convex. Upper contour sets are ordinal, so \(u^i\) is strictly quasi-concave. \(x_1^kx_2^k\) is Cobb–Douglas with exponent sum \(2k\): concave iff \(2k\le1\). (Along the diagonal, \(u^i(t,t)=t^{2k}\), which is convex for \(2k>1\), so concavity fails.)
(b) At an interior PO, if MRSs differed, a small trade would make both better off. \(MRS^i=x^i_2/x^i_1\) (the \(k\) cancels). Equality: \(\frac{x^1_2}{x^1_1}=\frac{1-x^1_2}{1-x^1_1}\Rightarrow x^1_2=x^1_1\). So \(x^1=(s,s)\) and \(x^2=(1-s,1-s)\).
(c) \(u_1=s^{2k}\), \(u_2=(1-s)^{2k}\), so \(u_1^{1/(2k)}+u_2^{1/(2k)}=s+(1-s)=1\). It bows inward iff \(2k>1\).
(d) Suppose an interior PO allocation \(x^1=(s,s)\), \(s\in(0,1)\), solved \(W(\lambda)\). Then in particular it would beat every other diagonal allocation, i.e. \(s\) would maximize \(f(s)=\lambda_1s^{2k}+\lambda_2(1-s)^{2k}\) on \([0,1]\). For \(2k>1\) and \(\lambda\ge0\), \(\lambda\ne0\), \(f''(s)=2k(2k-1)[\lambda_1s^{2k-2}+\lambda_2(1-s)^{2k-2}]>0\) on \((0,1)\), so \(f\) is strictly convex and \(f(s)\lt\max\{f(0),f(1)\}\): a contradiction. Interior PO points are never chosen; only the two corners are.
(e) \(v^i=(u^i)^{1/(2k)}=\sqrt{x_1x_2}\), which is concave (exponents sum to 1). The frontier becomes \(v_1+v_2=1\), and with \(\lambda=(1,1)\) every point on it, i.e. every PO allocation, solves \(W\). The PO set never changed; only the utility numbers did.

Exercise 21.6 Exam-inspired (zero weights)

One good, aggregate endowment \(\bar e\), \(u^1(x)=u^2(x)=x\), \(X^1=[0,a]\) with \(0\lt a\lt\bar e\), \(X^2=\mathbb R_+\), and feasibility \(x^1+x^2\le\bar e\).

  1. Verify that HH, FF and CC hold and that the \(u^i\) are strictly increasing. Draw \(U\). (5 pts)
  2. Find all solutions of \(W(\lambda)\) for \(\lambda=(1,0)\). Which are Pareto optimal? (10 pts)
  3. Find all solutions for \(\lambda=(\lambda_1,\lambda_2)\gg0\). Distinguish \(\lambda_1>\lambda_2\), \(\lambda_1=\lambda_2\), \(\lambda_1\lt\lambda_2\). (10 pts)
  4. Which weights support the allocation \((a,\bar e-a)\)? Are they unique up to scale? (5 pts)
  5. Prove that if \(W(\lambda)\) with \(\lambda\ge0\), \(\lambda\ne0\), has a unique solution, that solution is Pareto optimal. (10 pts)
  6. How would (b) change without free disposal, i.e. with \(x^1+x^2=\bar e\)? (5 pts)
Show solution

(a) \(X^1,X^2\) are intervals (convex); there is no production, so the aggregate set \(-\mathbb R_+\) (disposal) is convex; linear \(u^i\) are concave and strictly increasing. \(U\cap\mathbb R^2_+=\{u_1\le a,\ u_1+u_2\le\bar e\}\) (figure in §6).
(b) Maximize \(x^1\): \(x^1=a\), and any \(x^2\in[0,\bar e-a]\). Only \(x^2=\bar e-a\) is PO.
(c) The objective is \(\lambda_1x^1+\lambda_2x^2\); at an optimum nothing is disposed (\(\lambda_2>0\)), so \(x^2=\bar e-x^1\) and the objective is \(\lambda_2\bar e+(\lambda_1-\lambda_2)x^1\). If \(\lambda_1>\lambda_2\): \(x^1=a\). If \(\lambda_1\lt\lambda_2\): \(x^1=0\). If equal: any \(x^1\in[0,a]\). All of these are PO, as the theorem's sufficiency half promises.
(d) From (c), it is a solution whenever \(\lambda_1\ge\lambda_2\ge0\) (with \(\lambda\ne0\)). Not unique: the frontier has a kink there.
(e) §6, "a rescue".
(f) Then \(x^2=\bar e-x^1\) is forced; \(\lambda=(1,0)\) has the unique solution \((a,\bar e-a)\), which is PO, consistent with (e). The non-PO maximizers in (b) exist only because the planner can waste goods it gives zero weight to.

Key takeaways

  • \(U=\{u: u_i\le u^i(x^i)\text{ for some feasible }x\}\) lives in utility space and is downward comprehensive. Pareto optima map to its boundary.
  • Convex \(X^i\) and \(Y\) make feasible allocations convex; adding concave \(u^i\) (CC) makes \(U\) convex. Concavity is cardinal; quasi-concavity is not enough.
  • Sufficiency: \(\lambda\gg0\) and \(\bar x\) solves \(W(\lambda)\) \(\Rightarrow\) \(\bar x\) is PO (no convexity needed). Necessity: PO \(\Rightarrow\) \(\bar x\) solves \(W(\lambda)\) for some \(\lambda\ge0\), \(\lambda\ne0\) (supporting hyperplane; the sign comes from comprehensiveness).
  • Zero weights may be needed to support corner optima, and they let non-PO allocations solve \(W\). A unique maximizer is always PO.
  • \(\lambda\) is the normal to the frontier; at a smooth point the frontier's slope is \(-\lambda_1/\lambda_2\). Choosing \(\lambda\) means choosing a distribution of welfare.
